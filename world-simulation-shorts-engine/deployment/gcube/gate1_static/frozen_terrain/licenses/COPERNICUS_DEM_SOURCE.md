# Copernicus DEM GLO-30 source preservation

Input is four user-uploaded Copernicus_DSM_COG_10 GeoTIFF originals.
No external retrieval, raster re-encoding or elevation modification is performed.
The original source manifests, tile names and SHA-256 hashes are retained.
Product: Copernicus DEM GLO-30 (DSM), approximately 1 arc-second spacing.
The Copernicus DEM GLO-30/GLO-90 public-data license and attribution requirements
apply to the originals and derived height data; packaging does not relicense them.
Product information: https://dataspace.copernicus.eu/explore-data/data-collections/copernicus-contributing-missions/collections-description/COP-DEM
License reference: https://spacedata.copernicus.eu/collections/copernicus-digital-elevation-model
Attribution: Copernicus DEM, European Union / ESA / Airbus.
These links are product references, not claims that TIFFs were downloaded here.
