# Synthetic director fixtures

These two original, explicitly fictional EPSG:4326 datasets exercise different hemispheres, nonrectangular polygons, geographic anchors, bent lines, and label lengths. They are mathematical test inputs. They are not reference 64306 geography, verified coastlines, historical territories, or measured boundaries.

Neither fixture supplies a real basemap or establishes renderer capability. A passing contract or camera-math test does not establish an actual Studio draw, a geographic reproduction, or visual quality. No completed reference binding is replaced with either fixture.
