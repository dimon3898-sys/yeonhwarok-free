WORLD ENGINE — REFERENCE DIRECTOR V1 제한적 복구 지시

기준: 원격 커밋 5cc9b98 및 기존 review ZIP. 먼저 CAPABILITY_GAP_AND_PATCH_MAP.md, DATA_BINDING_AND_SOURCE_REPORT.md, SOURCE_DETAIL_AND_LICENSE_REPORT.md, REMAINING_LIMITS.md를 읽어라.

목표: 기존 카메라·핀·글자·경계 규칙을 보존하면서 실제 지도 렌더링을 차단하는 두 게이트를 해결한다. 범용 엔진 우선. 역사 80초 FINAL 제작 금지.

PHASE 1 — 보호 렌더러 최소 확장 설계 및 승인 범위
1. web/map_infographic_v1/renderer.mjs에만 필요한 변경을 함수·라인·전후 계약으로 명세한다. 기존 updateCamera(bounds), flat 기본 경로, globe 경로, source admission, 최소 해상도 제한을 유지한다.
2. 선택형 REFERENCE_SIMILARITY_2D_V1의 지도 공통 forward/inverse, screen(point), inverseScreen(pixel), 회전 viewport 4코너 source envelope, 실제 지형 역샘플링을 구현한다.
3. 완성된 프레임의 후처리 회전이나 overlay만 회전하는 가짜 구현은 금지한다.
4. 보호 파일 변경 전 백업·기준 SHA·변경 diff·기존 307개 보호 파일의 영향과 복구 방안을 제출한다. 이번 지시는 위 파일의 제한적 변경을 승인하되, 다른 보호 파일·FINAL·캐시 변경은 승인하지 않는다. 보호 기준 해시를 몰래 갱신하지 말고 원본 해시와 변경 해시를 모두 보고한다.
5. 무료 CPU/SwiftShader에서 기존 기본 경로와 opt-in 경로를 실제 draw/readPixels로 검증한다. 실패 시 제작 중단.

PHASE 2 — 정밀 자료 조사·확보
1. 레퍼런스의 핵심 장소는 미식별 상태다. 먼저 장소 식별 근거를 확보한다. Peñón de Vélez de la Gomera 등 후보를 검증 없이 확정하지 않는다.
2. 검증된 핵심 Point, 상세 Polygon/MultiPolygon, 순서 있는 LineString, 지리적 측정 근거, context 영역, basemapSourceIds를 각각 출처·라이선스·날짜·좌표계·해상도·SHA와 함께 확보한다.
3. 자료의 사용·재배포 허가를 확인한다. 외부 접근이 불가능하면 확인 불가로 보고한다.
4. 85 m는 독립 검증 전까지 원본 영상에 등장한 텍스트로만 취급한다. 가짜 지형·사각형·단순 업스케일로 자료를 대체하지 않는다.

PHASE 3 — 조건부 실제 렌더링
1. PHASE 1 실제 픽셀 PASS와 PHASE 2 자료 게이트 PASS가 모두 충족될 때만 진행한다.
2. 12개 기준 시점 native static draw, 두 개의 synthetic fixture 실제 draw를 검증한다.
3. 기존 전역 시간축 [29,575)에서 A 180프레임, B 180프레임, C 186프레임을 실제 Studio 경로로 제작한다. 창 경계에서 카메라·이벤트 상태를 초기화하지 않는다.
4. 레퍼런스와 같은 시점의 카메라 구도·대상 화면 크기·핀 위치·글자 등장·경계 각도·수치 유지 시간을 비교한다.
5. 자동 테스트 PASS와 사용자 영상 품질 PASS를 구분한다. 유료 GPU/API·배포·80초 FINAL 금지.
