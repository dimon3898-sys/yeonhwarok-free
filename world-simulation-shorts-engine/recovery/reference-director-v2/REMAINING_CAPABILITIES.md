# Remaining capability and production limits

The native extension and additive graphic consumers are separate from a
completed, source-admitted Studio production path. Passing syntax, CPU contracts
or isolated graphic draws cannot imply that path is ready.

| Capability | Current contract / remaining work |
| --- | --- |
| Opt-in native flat projection | Real shared camera, screen/inverse, four-corner footprint and terrain inverse sampling are implemented; the actual pixel audit decides its verified scope. Default/globe pixel determinism is separately audited. |
| Source quality admission | Actual selected raster bytes are SHA-verified on opt-in. Density, gutter, minimum camera extent, CRS/NoData and floating-point precision guards remain mandatory. |
| Geographic precision | The numerical 0.25-pixel guard is not a survey-accuracy certificate. Fine GIS/source registration must be independently verified. Unsupported polar/dateline/globe transitions fail explicitly. |
| Country overview through tiny local detail | One qualified raster per active draw is supported. A coherent multi-resolution hierarchy and transitions are **not implemented or verified** by this primitive. An upscaled global RGB or an unrelated regional crop does not solve it. |
| Generic event program | Strict externally supplied PIN/LABEL/AREA/LINE/METRIC data, global timing, source traces and bounded windows are implemented. These source labels do not certify historical/geographic facts or licenses. |
| New graphic consumer | Five actual synthetic component draws exist; the projection in those tests is a stub and the background is solid. This is **not** actual native map integration or a complete director profile. |
| Native map + composition + source-bound profile | The call-order adapter is implemented, but actual combined profile pixels and Studio integration remain unverified. Source/admission checks cannot be bypassed to exercise the reference job. |
| Production source registry | New renderer SHA must be bound by a separate admitted profile. The old V1 seal correctly remains pinned to the old renderer and has not been altered. |
| Fine reference data | Hero identity, Point, detailed Polygon, ordered real boundary LineString and sufficient licensed basemap remain unverified/missing. `85 m` remains an observed reference string only. |
| Studio MP4 / image quality | Phase3 is blocked until both prerequisite gates pass. No new reference/Studio MP4, NVIDIA result, user quality approval or FINAL promotion is claimed. |

Input-specific selection IDs remain authoring data in the supplied profile.
Engine code contains no reference geography/timing branch. Source data are not
invented, simplified into false detail or redrawn from reference pixels.
