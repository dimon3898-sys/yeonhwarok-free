2. 네트워크 변경을 저장하고 **Publish(게시)** 합니다.
3. 게시가 완료되었다고 알려주면, 실제 적용 정책과 접근부터 재확인합니다.

추가했습니다: `en.wikipedia.org`, `www.ign.es`, `overpass-api.de`,
`www.openstreetmap.org`, `ejercito.defensa.gob.es`.

서로 다릅니다. 현재 도구에는 초안 읽기/저장 기능은 있지만 게시 실행 기능은
노출되어 있지 않습니다. 게시 성공이나 Publish 버튼 비활성화의 원인을
추정하지 않습니다. GPU 토큰·가짜 값 추가 또는 기존 Secret 삭제는 필요
조치로 제안하지 않습니다.
