# ASTRA CPU provider contract v1

Providers are independent Python APIs in `astra_cpu.providers`: `TerrainSource`, `BathymetrySource`, `SurfaceTextureSource`, backed by supplied source metadata and a raw-byte reader. They never import the WORLD ENGINE renderer, create GPU textures or infer story/countries. `ArchiveCatalog` reuses the permanently saved ASTRA ZIP. License review is an explicit caller assertion tied to the existing evidence, not inferred from a URL.

`DataRequest(bbox, crs='EPSG:4326', target_ground_resolution=None)` uses `[west,south,east,north]`. A west>east request splits at the date line. Crop selects original centers in half-open bbox ranges, reports actual cell-edge support, and never pads, resamples or coerces nodata to zero. A requested resolution is intent; existing sample spacing/detail remains unchanged. Other output CRSs require explicit future reprojection and currently return an error.

`provide(request, source_version=...)` returns `ProviderResult` with `status, sourceId, sourceVersion, sourceURL, bbox, CRS, nativeResolution, outputResolution, verticalDatum, nodata, attribution, SHA-256, error`, plus actual raster parts, coverage and warnings. Statuses are `available`, `unavailable`, `auth_required`, `version_changed`, `license_unverified`, `invalid_data`. Planning uses `planned`, never `available`. Source-version mismatch and unreviewed license stop before reading source bytes. Invalid raw SHA/format/CRS yields `invalid_data`; no geographic support or no valid samples yields `unavailable`.

`available` means validated CPU samples are present, not full-camera coverage, coastline accuracy, physical GPU readiness or visual quality. `coverage.complete` concerns grid extent only. Requested bbox, actual part bounds, valid sample count and absent parts remain explicit. Masks and nodata are independent of stored raw numeric values. Signed GEBCO elevation does not classify ocean; derived depth requires an external boolean ocean mask and is unresolved when absent.

`RasterData(values,x,y,valid,metadata)` preserves original dtype/values and actual Float64 sample-center axes. `transform` is the actual rectilinear six-value GDAL corner transform; Point data is not shifted again. Source row direction remains intact. `north_up()` only reverses rows/axes losslessly. `crop()` updates actual origin without inventing coordinates. Numeric arrays are read-only copies. Datum, source hashes, registration, raw color tags and resolutions are recorded separately; Copernicus EGM2008 and GEBCO mean-sea-level assumptions are not treated as identical.

Neutral serialization is `ASTRA_NEUTRAL_RASTER_V1`: NPZ containing `values`, `x`, `y`, boolean `valid`, and UTF-8 JSON metadata stored as uint8. Pickle/object arrays are forbidden. Numeric nonfinite nodata values are retained; metadata uses explicit nonfinite/binary markers where JSON requires them. Dtype, shape, bbox and hashes are checked on load. This format is a CPU exchange/cache artifact; GPU texture format, endianness conversions, row upload direction, packing, allocation and VRAM limits remain unassigned until hardware integration.

The three direct parsers accept exact source bytes and expected input hashes. Terrain uses installed GDAL/NumPy; bathymetry uses installed libnetcdf with serialized native calls and closed handles; surface uses Pillow/OSR. No extra Python package is required. Native source resolution is catalogue provenance; PNG grid spacing alone never proves source detail or color-space/physical-albedo accuracy.

`DownloadRequest` in `astra_cpu.download_contract` carries source identity/version, HTTPS URL, hard byte bound, expected raw SHA when known, optional inclusive byte range/ETag/object size, bbox, CRS, resolution and metadata hash. It supplies a stable handoff between request planners, transport and raw cache. Existing credentials must be applied through secure transport configuration, never URL credentials or saved request files.

## Composed execution and Scene boundary

`CpuDataPipeline(catalog, cache=None, mode=...)` composes the existing three provider APIs with FileCache; no renderer import or HTTP request. Exact canonical source/sidecar paths and exactly one PGW+PRJ are validated before hash-based cache reuse. Derived identities bind complete source/auxiliary metadata and the whole request context; date-line halves retain correct current aggregate coverage. `prepare_scene` validates config only; `pipeline.prepare` explicitly executes selected CPU bindings. GPU activation remains false. Runtime arrays and neutral artifacts are documented here; GPU row packing/texture allocation is intentionally deferred.
