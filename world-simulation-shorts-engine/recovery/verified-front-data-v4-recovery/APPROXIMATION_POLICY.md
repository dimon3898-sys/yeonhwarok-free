# Approximate archival-map reference registration

This is an additive FACT_BASED_VISUAL_GRADE method. The existing V4 known-source-CRS tool, its admission requirements, thresholds and evidence remain unchanged.

The Army's map legend identifies a dated UN front. It does not identify a geodetic projection, datum or surveyed occupation polygon. Source projection and total positional accuracy therefore remain unknown. EPSG:4326 describes the reference points and output coordinates only.

Each map uses its own original raster pixels, six fitted named-place anchors and three separately held-out anchors from the existing hash-pinned Natural Earth public-domain data. Locality/road/urban anchors are approximate, not survey control. The original control split precedes the reported fit; the initial 5,000 m model-residual budget was set after exploratory measurements. This is not a blind accuracy trial. The budget is fixed for this profile and is not changed to admit a failed result.

Only original trace edges whose two endpoints are inside the fitted controls' convex hull are retained. No extrapolation, synthetic intersection vertex, coastline closure, occupation polygon, enemy complement or gap bridging is permitted. A convex hull includes a straight edge between supported endpoints; source tracing still requires independent visual inspection of the actual ink.

Independent checkpoints test the fitted model. Their hull describes the spatial distribution of that validation, rather than the source raster's support boundary. Here it is south-limited, and the retained northern fronts extend outside it. An Incheon checkpoint is also outside the fitted hull. These are explicit warnings, not silently removed checks. No spatially uniform accuracy is certified. Registration residuals must never be reported as total historical-map accuracy.

The source line and source-pixel trace were inspected by Codex agents and independently viewed by the root agent. This is not a human historian's certification. Runtime admission is limited to a dated, approximate, partial depiction of the source UN front, with an on-screen qualification. The 27 July 1953 line is not claimed to be an exact armistice Military Demarcation Line.

The 80-second parent plan remains preserved. Separate source-bound scheduling replaces the last two chapters' schematic graphics with the 12 November 1951 and 27 July 1953 source snapshots. Unobserved dates are not interpolated. Earlier chapters retain their explicitly dated schematic context. This is a partial archival-data upgrade, not a claim that all twelve events now have exact fronts.
