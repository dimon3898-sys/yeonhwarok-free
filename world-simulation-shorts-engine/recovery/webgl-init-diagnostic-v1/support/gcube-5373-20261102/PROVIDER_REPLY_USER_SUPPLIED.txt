현재 해당 노드에 누락된 EGL 벤더 설정을 추가하였으며, 조치를 완료한 상태입니다.

2. 웹 터미널 연결 종료 관련

① 컨테이너 exec/PTY 상태 확인 결과
노드 런타임 로그를 확인한 결과, 다음과 같은 기록이 확인되었습니다.
23:06:10 전후 : 명령 전달 시점에 터미널 세션 종료 또는 오류 기록 없음
23:07:04.649 : 컨테이너 중지 요청 기록
23:07:04.941 : Stdout copy error: read /dev/ptmx: input/output error 발생

해당 오류는 컨테이너 중지 과정에서 터미널 PTY 세션이 종료되며 발생한 것으로 판단됩니다.

② WebSocket Close Code 및 Reason
문의주신 WebSocket Close Code 및 Reason 정보는 현재 서버 측에 별도로 기록되지 않아 제공해 드리기 어려운 점 양해 부탁드립니다.

③ 명령어 전달 여부 및 연결 종료 원인
확인 결과, 해당 시점에 컨테이너 내부의 셸 세션은 유지되고 있었으나, 입력하신 명령어가 실제 셸까지 전달되었는지는 현재 기록만으로 확인하기 어렵습니다.
다만, gcube 웹 터미널에서는 1회 입력 데이터가 약 32KB(32,768바이트)를 초과할 경우 연결이 종료되는 제한 사항이 있습니다.
이에 따라 해당 제한으로 인해 브라우저와 서버 간 연결이 종료되었을 것으로 판단됩니다.

웹 터미널 이용 시에는 안정적인 사용을 위해 1회 입력 크기를 30KB 이하로 유지해 주시기 바랍니다.
또한 대용량 스크립트나 긴 명령어를 실행해야 하는 경우에는, 웹 터미널에 직접 입력하기보다는 외부 저장소를 연결하여 스크립트 파일을 저장한 후 터미널에서 실행하는 방식을 권장드립니다.

서비스 이용에 불편을 끼쳐드린 점 다시 한번 사과드리며, 안내드린 조치 사항을 확인하신 후에도 동일한 문제가 발생하는 경우 gcube 홈페이지의 QnA를 통해 문의해 주시기 바랍니다.
