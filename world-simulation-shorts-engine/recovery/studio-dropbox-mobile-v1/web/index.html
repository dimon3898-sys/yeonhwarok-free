Dropbox 백업 연결

휴대폰에서 한 번 연결하면 토큰 갱신과 백업 인증을 자동으로 처리합니다.

  1. Dropbox 승인
  2. 안전하게 저장
  3. 백업 검증

연결 주소를 준비하고 있습니다

안전한 HTTPS 주소와 GitHub 권한이 준비되면 이 화면에서 연결할 수 있습니다. PC나 터미널은 필요하지 않습니다.

Dropbox 접근 승인

이미 만든 App Folder 앱을 사용합니다. Refresh Token을 복사할 필요가 없습니다.

최초 한 번만: Dropbox App Console → 해당 앱 → Settings의 App key. 기존 백업에 사용한 같은 앱이어야 합니다.

처음 연결할 때만 확인

Dropbox 앱의 Permissions에서 files.content.read, files.content.write, files.metadata.read를 선택하고 Submit을 누릅니다.

Settings → OAuth 2 → Redirect URIs에 아래 주소를 추가하고 Add를 누릅니다.

GitHub에 안전하게 저장

Dropbox 승인을 받았습니다. 발급된 토큰은 이 탭의 메모리에만 있으며 화면에 표시하지 않습니다.

현재 연결에는 Secret 저장 권한이 없어, 최초 한 번 GitHub의 정식 권한 승인이 필요합니다.

휴대폰에서 GitHub 권한 준비

GitHub → 프로필 → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.

짧은 만료일을 선택하고 Repository access는 Only select repositories → yeonhwarok-free만 선택합니다.

Repository permissions: Secrets와 Actions를 각각 Read and write로 설정한 뒤 Generate token을 누릅니다. Contents 쓰기나 관리자 권한은 필요하지 않습니다.

생성한 값을 아래 비공개 입력칸에만 붙여넣습니다. 채팅이나 소스에 보내지 않습니다. 이 페이지는 그 값을 저장하지 않습니다.

GitHub 권한 화면 열기

기존 실행 코드와 연결하기 위한 앱 설정입니다. App Console → Settings → App secret의 Show에서 확인합니다. GitHub Secret으로 암호화 저장하며 Dropbox 로그인 요청에는 넣지 않습니다.

기존 암호화 키는 유지합니다. 백업이 이미 있는데 키가 없으면 안전하게 중단합니다. 유료 GPU는 시작하지 않습니다.

검증 기록 보기

GitHub 작업 완료와 실제 백업 성공은 구분합니다. PASS 기록을 확인하기 전에는 GPU 제작을 시작하지 않습니다.

PC · Docker · 터미널 없이 연결합니다. 이 페이지는 영상을 제작하거나 GPU를 배포하지 않습니다.
