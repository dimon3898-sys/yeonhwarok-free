# ASTRA MASTER V2 — 실제 출력 검수 결과

**판정: NEEDS_REWORK / USER_REVIEW_REQUIRED.** 구현과 실제 출력은 보존했지만 요청한 모든 화면 연출이 완성됐다고 선언하지 않는다.

이번 작업은 첨부 ZIP을 32MiB 전송 제한으로 직접 풀지 못했다. 대신 저장소의 고정 `9d45573d660263278878b410bfdebb53589cb654`에 있는 독립 실행 MASTER 전체 4,463행을 읽고 작업했다. MASTER SHA는 `a01ca932f203f732ba5a9931e483a3d80403b69d25dc2e09463ce710c43e68cd`이며, ZIP 내부 파일을 모두 열었다는 주장은 하지 않는다. 현 사용자 요청의 구현 승인을 과거 분석 문서의 중단 문구보다 우선 적용했다.

## 완료한 변경

- 원본 Plan/FINAL을 유지하고 별도 파생 Scene에서 부산 도식 반복, 후기 지도 날짜 역행, 휴전 협상 누락을 교정했다.
- 공식 Appleman Map I의 6월 28일 부분 전선을 기준점·held-out 검증과 원본 trace로 연결했다. 3개 열린 조각·19점이며 전체 점령 면이 아니다. 원 투영법과 총 역사 위치 오차는 미확인이다.
- 기존 V5/reference·Area·ASTRA·Glyph를 호출하는 strict opt-in 계약과 실제 소스/hash 바인딩을 연결했다. 없는 자료·기능은 조용히 기본값으로 바꾸지 않는다.
- 실제 ASTRA 합성 texture의 canvas·소유자·global frame·bounds 정합을 검사했다. 이 핸들 연결만으로 역사적 scalar 조명이 연결됐다고 표시하지 않는다.

## 실제 산출물과 검증

- 실제 WORLD ENGINE / Chromium SwiftShader에서 동일 80초 시간축의 16개 PNG를 새로 draw/readPixels했다: 0,5,…75초, 1080×1920.
- 지정된 M1/M2/M3의 실제 연속 프레임을 출력했다: `[600,700)`, `[865,965)`, `[965,1100)` — 100/100/135프레임. clean 3개와 전역 프레임 번호 검수용 3개를 H.264·30fps·무음 MP4로 인코딩하고 전체 디코딩했다. **영토 확장 성공 영상이 아니라 자료 검수 영상**이다.
- 주 실행은 고유 348프레임, 별도 경계 검사는 51시점(추가 draw 44, 이미 그린 동일 7개 증거 재사용)이다. 기존 5초 영상이나 기존 PNG를 새 렌더로 사용하지 않았다.
- 집중 CPU/명시적 모의 검사 84개 PASS. 기존 FINAL/보호 소스 변경 0건. 실제 NVIDIA 실행, 유료 GPU, 전체 80초 MP4, FINAL 승격은 실행하지 않았다.

## 아직 달성하지 못한 화면

1. **LOCAL 확대:** 원본 색상·해안 상세도와 정확도·사건 geometry가 admission을 충족하지 않는다. 별도의 Regional 자료 검수 범위를 LOCAL 성공으로 대체하지 않았다.
2. **양측 통제 면·연속 확장·이동 전선:** 12사건의 전체 통제 영역과 전환 근거가 없다. source schedule의 860프레임은 명시적 unknown이며, M2에서 역사적 점령 morph를 그리지 않았다. partial line을 해안으로 닫거나 반대 진영 색으로 보완하지 않는다.
3. **신규 부분선의 가시성:** frame 300의 세 조각 draw는 확인했지만 작은 배율과 기존 서울 핀/지명 마스크에 대부분 가려진다. 읽히는 전선으로 품질 PASS할 수 없다.
4. **제목 안정성:** M1의 641→642프레임에서 제목 중심이 한 프레임에 1,487px 이동한다. 매 프레임 안전 배치가 다른 행을 선택하기 때문이다. 보호 경계 검사를 무시하지 않고 실제 전체 카메라 구간에 고정 예약을 검증하는 추가 작업이 필요하다.
5. **역사 군대 표식·오디오:** 검증된 부대 좌표와 오디오 의미/cue 근거가 없어 빈 표식, `enabled=false/gain=0/cues=[]`를 유지했다.

완전한 통제 geometry를 받기 전 렌더러가 이를 만들어 내는 방식은 사용하지 않는다. 새 계약의 현재 운영 Studio/OCI 이미지 포함도 검증하지 않았으며, 이번 소프트웨어 출력으로 배포 준비나 NVIDIA 품질 PASS를 선언하지 않는다.
