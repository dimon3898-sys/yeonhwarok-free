## Historical control and continuous frontier movement

The original five schematic held-cores and eight approximate partial archival fronts remain preserved. A new source-qualified approximate ROK partial front for the evening of 28 June 1950 is registered from Appleman Map I, PDF page 49. It contains three open fragments, 19 retained source points and 16 source edges, not a complete ownership polygon. Fit maximum residual is 775.70 m and independent held-out maximum residual is 3,661.88 m; the original projection and total historical positional accuracy remain unknown. These residuals are model checks, not a claim of 3.7 km total historical accuracy.

The new derived 2,400-frame source schedule contains 1,110 frames with approximate observed partial-front evidence, 430 frames with explicitly schematic held-cores and 860 frames with unknown event geometry. This is a classification of selected source evidence, not a measurement of territory ownership or a statement that all historical stages are complete. Global-frame 300's actual probe draws all three new source fragments through preserved Area V3 and displays the approximate-partial qualifier. Frame 0 displays the event with an explicit missing-control-source label rather than inventing a control polygon.

The P0 source catalog still supplies no complete two-owner control fields or supported topology/correspondence for the twelve chapter endpoints. `control_contract.py` and `control_bridge.mjs` deliberately return null control endpoints and draw zero historical owner morphs. Partial fronts are not closed to coastlines, and neutral areas are not filled with an inferred enemy complement. Existing scalar and Area engines are preserved; snapshot holds/crossfades do not satisfy continuous occupation expansion.

The minimum evidence needed for a future ownership transition is dated, source-qualified start/end control geometry and a supported correspondence/transition explanation. Additional source digitization must preserve map dates, verified fragments, excluded gaps and total positional uncertainty. The local branded control-frame guard checks an explicitly absent owner draw; it does not prove that the existing territory, frontier and lighting GPU passes consumed one complete ownership field. There is no basis to declare the required Seoul control-morph sample M2 complete merely because a diagnostic clip exists.

Existing official source candidates are already retained. The Incheon map distinguishes positions on the nights of 15 and 16 September; the Seoul map distinguishes positions on 19, 21, 24 and 28 September. Their next useful operation is independent geographic registration using verified, stable physical control points, followed by tracing only the actual dated source fragments. Grey built-up city areas, advance arrows and planned lines must not become occupied polygons. No request to re-upload these existing sources or collect every map is necessary.
