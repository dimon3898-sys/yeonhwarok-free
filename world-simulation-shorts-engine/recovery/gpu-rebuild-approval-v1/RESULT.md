**중지와 영구 삭제는 별개다.** 공식 CLI도 stop과 delete를 별도 동작으로 제공한다. 중지는 배포된 GPU 서비스 종료이며 등록 상태가 종료로 바뀐다. delete는 되돌릴 수 없는 별도 워크로드 삭제다. 중지가 컨테이너 파일시스템을 보존하는 일시정지라는 보장은 없으며, 사용자 수용 범위의 private 자료는 유실될 수 있다. Dropbox 저장소를 해제하거나 삭제할 필요가 없다. GitHub 저장본과 GHCR 이미지는 별도로 보존된다.

기존 수집기는 내부 이름 `RTX4080S`에 `SUPER` 문자열이 없으면 행을 놓칠 수 있었다. 공식 CLI가 우선 표시하는 `productName`과 명시적 숫자 문자열을 지원하는 독립 adapter로 보완했다. 기존 수집기·원본·렌더러는 수정하지 않았다. 이번 응답은 `productName`으로 2개 항목이 확인됐다. 누락값을 `0`원 또는 `KRW`로 추정하지 않았다.
