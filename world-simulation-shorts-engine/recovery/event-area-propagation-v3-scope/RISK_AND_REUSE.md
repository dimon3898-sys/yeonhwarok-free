## New common contracts needed before implementation

These names describe scope, not existing implemented APIs.

- **Area/Propagation Intent:** supplied Polygon/MultiPolygon, supplied point/line front where appropriate, source identity, geometry role, event relation and semantic status. Observed, reported, forecast and illustrative geometry must be distinguishable data; the renderer cannot infer which one a shape represents.
- **Time-step Geometry:** immutable geometry snapshots or authored keyframes with explicit order, time basis and source binding. The first implementation should display supplied evolution deterministically. It must not claim that interpolation predicts tsunami waves, war fronts, typhoon fields or disaster spread.
- **Area Frame State:** random-access integer-frame controls, bound current/next geometry identities, display fraction, visibility, safe support bounds, hold state and measured reservations. Visual time is distinct from observed event time. Missing physics is not filled in by a hidden recurrence.
- **Area Framing / Visual Admission:** full semantic extent across the active time window, actual projected area/front bounds, native output proof, safe-area containment and protected-graphic checks. Certification is bound to the complete area/time-step inputs, camera framing and output. A previous Line certificate is not transferable.
- **Area Overlay / Material Profile:** new finite-support Event fill/front emphasis, explicit layer order and conservative protected-pixel mask, independent of frozen region/boundary/glow materials.
- **Area Annotation Layout:** measured, related, safe candidates for new annotations and any supplied Metric. Existing graphic owners remain immutable; no text or Marker can be moved to resolve a new area's collision.

## Specific risks and safe split conditions

| Risk | Safe handling within new V3 scope | Split only the affected capability when… |
|---|---|---|
| Reusing a Line-only certificate for an Area | Validate full area/time-step extent through a new geometry-aware contract; reuse quality-grade principles and actual native output. | Required area framing cannot be certified without changing the frozen Detail/Camera inputs or issuing an unsupported certificate. Existing-current-view area work can proceed separately when safe. |
| Hidden source edits | Treat frozen modules as imports; add new contracts/adapters/pass/fixtures only. Compare protected source hashes at the future implementation protection point. | The proposed effect requires touching Final camera, renderer material, Line/Flow evaluator, glyph/layout or occlusion core. Isolate that part and report the exact required owner change; do not patch Final. |
| Wrong object, place or relationship | Bind geometry roles and source statements; use native projection. Event evolution is supplied data, not renderer inference. | Shape identifies the wrong geography/object, reverses a relationship or materially misstates an event. This is a semantic failure even when the overlay is attractive. |
| Whole-event crop | Frame the union of the semantic area/front extent across active supplied steps; examine the complete outline plus overlay support. Occlusion of reserved graphics is a display mask, not new geography. | The full event cannot remain meaningful/visible in the permitted safe framing. Do not silently crop to a dramatic fragment or force a closer camera. |
| Filled overlay hides Marker/Text/Metric/Title | Conservative pixel-preservation mask, correct typed reservations and readable remaining area/front support. Keep full semantic geometry for containment and progress. | Protected native pixels change, a critical text collision persists or masking makes the asserted area/front relationship unreadable. Change only the new overlay/layout candidate or separate that feature. |
| Holes / multipart / seam / horizon errors | Preserve authored topology; use available polygon-aware helpers only where their representation is supported. Keep projected front visibility explicit. | Triangulation fills a hole, disconnects/crosses the wrong parts, creates a false seam or displays backside geometry as front. Limit support to a certified representation rather than altering core projection. |
| Native material/Glow damage | Compose an independently owned overlay; native Primary material stays on and native Boundary/Glow unchanged. | A desired effect requires disabling native material, replacing terrain or reusing mutable native Glow targets. Separate the effect from the new Area bundle. |
| Random-access / motion inconsistency | Evaluate display state from the frame and supplied plan/time-step data, independent of earlier draws. Reuse deterministic frame conventions. | A feature needs an unprovided physics integrator, mutable simulation history, nondeterministic timestep or inferred event velocity. Scope it separately; do not add physics to the visual evaluator. |
| Quantitative claim from display geometry | Use supplied fixed/step values and actual measured text. Visual timing/ring scale is not evidence of physical radius, intensity or speed. | The proposed Metric materially asserts unsupported amplitude, wind speed, arrival time, casualty count or affected area. Omit that claim or separate the quantitative-data feature. |
| Unbounded shader/resources / broken shared context | Bound new geometry/resource capacity, preserve complete GL state and dispose only owned resources. Reuse state helpers read-only. | New pass corrupts the native frame/context, exceeds safe support or cannot meet the output's basic visual-quality budget. Simplify only the new pass. |

Unknown survey-grade absolute accuracy, unmeasured metre-level coast alignment, generalized GIS or mild native Terrain softness are **warnings**, consistent with `FACT_BASED_VISUAL_GRADE`. They do not automatically block scope or future Candidate creation when location, relation, shape meaning and actual mobile-output quality remain sound.

Blocking conditions remain concrete: wrong geography/false relation, full-event crop, severe visible terrain/geometric corruption, critical collision, materially false Metric or damage to a frozen Final owner. A missing capability in today's Line/Flow API is an implementation boundary to extend safely in V3; it is not grounds to rewrite Final or reject the entire Area/Propagation scope.
