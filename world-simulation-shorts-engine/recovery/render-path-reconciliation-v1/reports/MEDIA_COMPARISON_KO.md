원본 raw capture를 다시 대조하면 새 영상의 `[50,100)`은 **RGBA가 완전히 같은 한 프레임**이다. 해당 1.667~3.333초 구간의 H.264 미세 변화는 움직임 증거가 아니다. 새 영상의 앞/중간/뒤 각 50프레임은 raw RGBA 50/1/50종, camera bounds 48/1/1종이다. 반면 옛 영상은 raw RGBA와 camera bounds 모두 150종이다.

새 source 범위의 처음 50프레임에는 현재 장 제목보다 이른 BUSAN→NORTH_ADVANCE 맥락 도식이 보이며, 마지막 50프레임은 NORTH_ADVANCE→SEOUL_WITHDRAWAL이다. 원본 시간축·날짜/도식 한정 문구를 그대로 보존했으므로, 이 창을 일별 실측 점령선의 연속 재현으로 소개하면 안 된다.

## 레퍼런스 전체 흐름

- 0~5.18초: 반도 전역의 양 세력·국기, 구도 전환과 확대.
- 5.18~10.18초: 보라 영역이 빨강으로 전진하고 불규칙 경계와 밝은 강조가 함께 이동. 카메라도 사건을 추적.
- 10.18~17.8초: 추가 전선 변화와 사건·무기 그래픽 등장.
- 17.8~23.8초: 항공기·전투 그래픽이 전선 주변을 지나며 북쪽으로 시선 이동.
- 23.8~28.6초: 북쪽까지 보라 영역이 확장하고 표식이 이동.
- 28.6~31.813초: 국기색 반도형 종료 그래픽으로 전환.

레퍼런스의 사건·시대는 현재 역사 장면과 다르므로 시간축을 강제로 맞추지 않았다. 레퍼런스 UI·자막·오디오를 새 영상의 재료로 사용하지 않았다. 레퍼런스 audio는 전체 디코딩했지만 듣지 않았으므로 특정 효과음이나 음질 동등성은 판정하지 않는다.

## 판정과 한계

**VISUAL_NEEDS_REWORK**. 새 영상이 없어진 고급 렌더러를 쓴다고 추측하거나, 반대로 고급 기능을 모두 실제 사용했다고 주장할 수 없다. 확인된 것은 서로 다른 데이터·프리셋·합성 계약이 서로 다른 화면을 냈다는 사실이다. 실제 import/생성/설정/실행 연결의 원인은 별도 코드 호출 경로 증거와 함께 판정해야 한다.

`MEDIA_COMPARISON.json`에는 전체 프레임 디코딩 결과, 각 1초 수치, 음원 전체 디코딩 결과, source-bound raw trace 요약을 기록했다. 색 임계치 비율은 화면 진단이며 지리 점령 면적이 아니다. `OLD_VS_KNOWN_NEW.png`는 양 파일의 실제 프레임 0/74/149를 비교한다. 레퍼런스 UI나 음원을 포함하지 않는다. 이번 분석에서 새 영상 렌더링·유료 GPU 실행·보호 소스 변경은 수행하지 않았다.
