# Original World Engine SFX

These waveforms are the existing Cinematic World Map project's original
procedural sounds from `engine/rhythm_sound.py`, dedicated to the public domain
under **CC0 1.0 Universal**:
https://creativecommons.org/publicdomain/zero/1.0/

Commercial video use is allowed. Attribution is not required. No reference
video, recording, stock audio, film, or game audio was sampled or copied.

The original module is preserved byte for byte in
`dependencies/rhythm_sound.py`; its SHA-256 and every WAV/PCM hash are recorded
in `ASSET_MANIFEST.json`. The WAV files use original stereo waveforms quantized
to signed PCM16 at 48,000 samples per second. The manifest includes the build
recipe. These are stylized interface/event sounds, not authenticated recordings
of military equipment or an assertion about real event acoustics.

The six Studio roles select existing categories. No new synthesizer, music,
speech, reference-audio extraction, or renderer has been introduced.
