# Universal data pipeline V1

This is an opt-in source-checkout review profile based on `e39969cbc76a071d34a38440d9551425e6d5e545`.
The legacy G1/G2, Studio production profiles, approved renderer, camera, scenes, videos and caches remain immutable.

The new input is a **structured data prompt**, not an unrestricted natural-language AI or an automated historical research service. Supplied facts select the existing generic Planner and its existing Area, Flow and Event engines. Unknown inputs and unsupported capabilities must be reported explicitly. Historical evidence gaps must remain visible; a citation, an official-looking URL or a user-written `VERIFIED` label cannot establish a historical boundary.

The new Studio profile reuses the authenticated HTTP server and detached source job manager. All development demos are bounded, loopback-only, free software WebGL review. They do not authorize NVIDIA use, GPU billing, G3 historical production, an 80-second film, deployment, or FINAL promotion.

## Evidence and gates

- `PROTECTION_RESTORE.md`: 307 original protected hashes and the reproducible external canonical PLAN.
- `reports/PROTECTION_BASELINE.json`: immutable snapshot of all 6,268 baseline tracked files.
- `PIPELINE_AUDIT.md`: actual pre-existing parser, compiler, Studio and rendering paths.
- `G3_BLOCK_CAUSE_REPORT.md`: separate policy, contract and historical evidence blockers.
- `reports/GATES.json`: current execution gates. A later production step may run only after its prerequisites pass.

Implementation and technical validation do not establish visual quality. User video review remains required.
