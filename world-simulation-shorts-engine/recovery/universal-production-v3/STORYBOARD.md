# 첫 80초 영상 구성 — 자료와 전선 도식을 분리

80초·30FPS·2,400프레임을 12개 장으로 구성합니다. 모든 구간은 반열린
프레임 범위이며 각 장은 200프레임입니다. 아래 시간은 영상 편집 시간이고,
실제 역사 사건이 동일한 기간 동안 진행됐다는 뜻이 아닙니다. 캐시·렌더 작업 경계는
장 경계와 구분합니다. 최초 움직이는 도식 전환 중간인 445프레임을 작업 경계로
사용하며, 장면별 작업도 총 12개를 유지합니다. 작업이 두 장에 걸치면 실제
전역 프레임에 맞는 사건 정보와 도식 날짜를 선택합니다.

각 장의 사건 제목·날짜와 함께 **실제 사용한 전선 도식의 기준일**을 별도로
표시합니다. 전환 중에도 출발·도착 도식 날짜를 표시합니다. 12장 전체를
정확한 일별 전선 복원으로 소개하지 않습니다. 일곱 장의 해당 사건 날짜
전선은 현재 자료에 없으며 이 한계를 화면과 품질 보고에서 유지합니다.

현재 공간 자료는 5개 도식뿐입니다. 기존 ROK 또는 국군·유엔군 보유 핵심
영역만 명시된 ownership 근거에 따라 색칠합니다. 나머지 국토를 자동으로
적 점령지로 간주하지 않습니다. 발발 도식에는 ROK만 연결하며 UN/미군의
참전을 앞당기지 않습니다. 검증된 역사적 부대 좌표가 없어 부대·국기 위치나
이동 경로를 새로 만들지 않습니다.

지형·ASTRA 재질·기존 Area 전선·카메라 기본 기능을 재사용합니다. 이 구성은
완전한 기존 V2 scalar 점령·백색/금빛 전선·군대 배치 효과를 전부 구현했다고
뜻하지 않습니다. 실제 렌더 경로의 적용 기능은 별도의 GPU 검증으로 판단하며,
80초 완성 영상이나 60분 제작 목표 달성은 아직 증명하지 않았습니다.

도식 전환 시간은 Scene 데이터에서 3초를 목표로 지정하고, 한 도식 슬롯의
절반을 넘지 않게 제한해 결과를 읽을 hold를 남깁니다. 이는 역사적 영토 이동
속도나 사건 발생 간격을 계산한 값이 아닙니다.
