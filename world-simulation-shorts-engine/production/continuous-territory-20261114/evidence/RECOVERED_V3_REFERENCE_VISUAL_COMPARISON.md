# 64306 레퍼런스 대비 V3 시각 비교

## 판정의 범위

레퍼런스 635프레임 전체의 프레임 시트와 V3 전체180프레임 및 대표 화면을 직접 비교했다. V3 최종 180프레임 검수 결과는 `final-a1-review/VISUAL_REVIEW.json`에 별도 기록한다. 기술 PASS와 레퍼런스 동등 이상 판정을 합치지 않는다. 임의의 품질 점수나 유사도 수치는 사용하지 않는다.

## 남은 시각적 한계

레퍼런스의 근접 해안 지도와 V3의 대륙 영토는 주제와 공간 규모가 다르다. 레퍼런스의 표식이나 군사 이동을 근거 없이 복제하지 않았다. 기존 소스 적합성 검사를 유지했으므로 확대를 강제로 높여 가짜 디테일을 만들지 않았다. V3는 가독성과 순차 연출을 개선했지만, 이것만으로 전체 시네마틱 완성도가 동등 이상이라고 단정할 수 없다.

다음 개선은 공통 소스 수준 선택과 근접 구도의 적합성을 먼저 확인하는 순서다. 필요한 공간 해상도와 실제 제공 지도 범위를 확인한 뒤, 해당 변경으로 무효화된 V3 카메라·소스 검사와 대표 프레임만 다시 검증해야 한다. 기존 PASS 재실행이나 유료 GPU 재시도는 필요 조건이 아니다. 최종 사용자 화면 품질 승인은 별도다.

## 증거

- `REFERENCE_TIMING_REPORT.md`: 구간별 시간·측정/추정 구분
- `reference/FRAME_MEASUREMENTS.json`: 실제635프레임 PTS와2D화면 운동 추정
- `reference/TIMING_ANALYSIS.json`: 경계·효과 발생 주석 및 신뢰도 제한
- `VISUAL_COMPARISON.jpg`: 원본283프레임과 V2/V3 화면 비교
- `evidence/CAMERA_MOTION_A2.json`: V3 카메라 모델 범위와 속도
- `PROBE_VISUAL_REVIEW.json`: 최종 제작 전 실제 대표화면 통과

현재 입력에 승인된 지도는0.025도 및1/60도 픽셀 간격의 두 수준이다. 이 입력 안에 더 세밀한 근접 지형 수준은 없다. 저장소나 외부 전체에 더 좋은 소스가 없다는 뜻은 아니다. `evidence/SOURCE_DETAIL_AUDIT.json`에 실제 메타데이터를 보존했다.

최종 판정: 기술 PASS, 전체180프레임 검수 완료. 레퍼런스 동등 이상 시각 품질은 NOT_PROVEN이며 사용자 승인도 PENDING이다. 기존 한국전쟁 상세 소스의0.0041667도 메타데이터와 C1 원본 기록을 찾았다. 실제 V3 관심 영역을 덮는 원본 바이트 및 공통 소스 등록을 먼저 확인해야 하며, 현재 MP4에 적용됐다고 주장하지 않는다.
