# 범용 자동 연출 감독 V2

`HISTORICAL_STATES_V2`는 원본 영토 상태 사이의 실제 도형 차이를 분석해 표시 시간, 카메라, 짧은 영역 강조를 정한다. 국가 이름·연도별 분기는 없다. 기존 `HISTORICAL_STATES_V1` 함수와 Area V3·Mercator·지도 원본은 보존한다.

## 기존 구현 조사와 변경

| 기능 | 판정 | V2 처리 |
|---|---|---|
| HISTORICAL_STATES_V1 | 최소 확장 | V1 유지, 별도 V2 정책 선택 연결 |
| Area V3 영토 상태 전환 | 재사용 | 원본 영역·기존 전환 연산 유지 |
| 카메라 키프레임·확대/축소 | 최소 확장 | 기존 Mercator 카메라와 5차 가감속, 새 타깃 선택 |
| 광역 지도 구도 | 재사용 | 기존 검증 지형 피라미드·밀도·범위 검사 유지 |
| 영토 경계 발광 | 최소 확장 | 기존 Area 패스로 차집합 영역만 짧게 강조 |
| 라벨 안전영역 | 재사용 | 기존 화면 라벨 배치·원자료 시기 연결 |
| 영상 길이에 따른 시간 배분 | 신규 공통 정책 | 변화 면적·상대 변화·분리된 부분 수·읽기 최소시간을 조합 |
| 영토 차이 분석 | 신규 공통 기능 | 합집합·차집합, 구면 면적 추정, 중심·범위·실제 화면 점유율 |

`territory_delta_v2.mjs`는 검증된 Polygon/MultiPolygon을 합치고 연속 상태의 차집합을 구한다. 원본 좌표 배열은 수정하지 않는다. 기존 도형 렌더러를 그대로 쓰며, 새로 추가한 polygon-clipping 0.15.7은 도형 연산만 담당한다. 배포본·라이선스·해시를 함께 보존했다.

## 시간과 구도

원본 연도·기간의 정밀도는 유지한다. 화면 시간은 역사 시간과 별개다. 최소 읽기 프레임을 먼저 확보하고 남은 정수 프레임을 변화량에 따라 배분한다. 합계는 정확히 180 또는 600프레임이다. 기존 Scene의 `time_steps[].transition_frames`와 beats가 실제 시간의 기준이며, Area V3는 이를 직접 소비한다. 변화 면적을 역사적 중요도로 판정하지 않는다.

도입은 첫 영토 전체, 전개는 변화 지역, 가장 큰 변화 구간은 절정, 마지막은 최종 영토 전체를 대상으로 한다. 변화량의 1% 미만인 작은 도형 조각은 카메라 범위를 불필요하게 넓히지 않도록 구도 선택에서만 제외한다. 해당 원본 영역과 차이 효과는 그대로 유지한다. 여러 큰 변화 지역은 함께 구도에 포함한다.

위도·경도·Mercator 축척은 왜곡하지 않는다. 모든 카메라 프레임을 기존 소스의 실제 해상도·지리적 범위에 대조한다. 작은 영토에는 소스 해상도로 표현 가능한 주변 지리 범위를 확보한다. 완전히 보이지 않는 개별 영역은 V2 이동 구도의 화면 밖에 있을 수 있으며, 원본을 잘라 새 영토로 저장하지 않는다. 마지막 전체 구도는 별도로 검증한다.

## 효과와 자료의 의미

추가 영역은 짧은 밝기 강조, 삭제 영역은 부드러운 소멸을 쓴다. 변화가 작으면 효과를 생략한다. 설정은 공통 `directorConfig`에서 제어하며, 원본 상태 차집합과 일치하지 않는 임의 영역은 거부한다. 원본 전체 영토의 소멸·등장은 기존 Area V3가 담당한다.

중심점은 카메라 통계값이다. 수도·전투 위치·군대 위치를 의미하지 않는다. 경로·전투·파동은 생성하지 않는다. 면적은 반지름 6371.0088km 구면과 원본 GeoJSON 선분을 이용한 추정치이며 측량 면적이나 역사적 확정 면적이 아니다.

## 검증과 재개

기존 V1·일본 PASS 및 영상 재실행은 0회다. `evidence/CHANGE_SCOPE.json`에 보호 대상과 해시가 있다. 신규 검사 중 드러난 작은 영토 확대 한계와 키프레임 끝점 부동소수점 문제는 실패 증거와 최소 재검증 범위를 보존했다.

합성 자료 10종과 V2 연결 검사 총 22개를 통과했다. 20초는 동일 정책의 컴파일·계약 검증이며 실제 20초 영상 렌더 성공을 주장하지 않는다. 공개 JSON 구조 검사 5개는 기존 역사 출처·기간 필드와 스키마의 불일치를 해소한 후 통과했다. 실제 화면·MP4 결과와 사용자 승인은 CHECKPOINT의 별도 필드로 판단한다.

대표 CPU 화면 확인 후에만 새 V2 6초 전체 영상을 생성한다. 성공한 대표 프레임이나 이전 영상은 이유 없이 반복하지 않는다. 유료 GPU·gCube·Studio GPU·이미지 빌드는 사용하지 않는다.
