# 범용 역사 상태 연결 구현

이번 변경은 기존 Planner → Area V3 → 지역 소스 승인 → Mercator 카메라 → 기존 Three.js 렌더러/라벨 패스 → FFmpeg 경로를 사용한다. 새 렌더러, 국가별 분기, 가짜 전선·진군 경로는 없다.

## 공통 변경과 검사 범위

| 변경 | 처리 | 새 검사 |
|---|---|---|
| 역사 시간 | 연도, 월, 일, BCE, 범위, 경계가 명시된 불확실 시기. 입력 정밀도 유지 | 10개 |
| 영토 상태 | 영토 또는 전선이 있으면 승인. 기존 Area 상태 교체로 확장·축소·분리 표현 | 7개 |
| 출처 | 재구성 자료의 버전·유효기간·좌표 해시·불확실성·라이선스 보존 | 6개 |
| 광역 지도 | 기존 Mercator 투영과 NASA 지형 소스의 검증된 창 사용. 비율 늘리기 없음 | 5개 |
| 다중 영역 검사 | 한 점 접촉과 구멍 안의 독립 영역을 허용. 실제 면적 겹침·공유 변·교차는 차단 | 7개 |
| 자동 연출/라벨 | 기존 출력 패스에 데이터 범위·시기 연결. 180프레임 수학적 가시 범위 확인 | 8개 |
| 첫 장면·장면 경계 | 첫 장면 원본 상태 표시, 뒤 장면의 영토·출처·역전 시간 검사는 유지 | 4개 |
| JSON 스키마 | 실행 계약과 동일하게 전선 없는 상태 승인. 완전히 빈 상태 차단 | 2개 |

총 49개 집중 검사는 이번 변경의 새 검사다. 기존 일본 영상의 PASS 검사를 재실행한 것이 아니다. 문법 검사 23개 모듈도 통과했다. 실제 픽셀 및 MP4 PASS는 별도 증거로 판단한다.

## 자동 선택의 의미와 한계

`presentation.automatic: HISTORICAL_STATES_V1` 하나를 선택한다. 카메라 좌표, 줌 키프레임, 효과 시각, 색상, 라벨 위치를 이번 주제 입력에 적지 않는다. 공통 정책이 실제 원본 상태의 범위와 출력 프레임 예산으로 결정한다. 자연어를 무제한으로 이해하는 LLM이 아니다. 검증된 구조화 자료와 유한한 주제 분류가 필요하다.

| 검증 항목 | 결과 | 근거 |
|---|---|---|
| 시작 카메라 | AUTO | 첫 원본 영토 범위와 소스 해상도 |
| 이동·확대/축소 | AUTO | 상태별 범위를 포함하는 카메라, 5차 가감속 |
| 영토 변화 | AUTO | 기존 Area 상태 간 투명도 전환. 이전 영토를 누적하지 않음 |
| 진군 경로 | 생략 | 출처에 실제 경로 없음 |
| 주요 사건 | 생략 | 출처에 사건 위치·정확한 정복일 없음 |
| 시각 효과 | 기존 Area 스타일 자동 사용 | 기존 경계·발광. 근거 없는 파동은 생략 |
| 연도·지역 라벨 | AUTO | 원본 기간 및 입력된 주제명. 재구성임을 표기 |
| 마지막 구도 | AUTO | 전체 상태 범위 수용, 마지막 45프레임 이상 고정 |

8개 항목 중 6개 자동 선택, 2개는 자료 없음에 따른 명시적 생략이다. 수동 보정으로 감춘 항목은 없다. 이번에 만든 공통 자동 연결과 기존 엔진의 렌더링 능력을 구분한다. 기존 생성기가 수정 전부터 이 자동 선택을 할 수 있었다고 주장하지 않는다.

카메라 구도를 위한 누적 외곽 범위와 화면에 표시하는 영토 상태는 별개다. 화면 영토는 각 시점 자료 그대로 교체되므로 축소·분리도 보존한다. 중간 투명도는 화면 전환이며 출처가 없는 중간 연도 경계를 뜻하지 않는다.

이번 광역 연결은 등록된 지형 범위, 소스 픽셀 밀도, 8192 최대 텍스처, Mercator 극지 제한을 모두 만족하는 경우에만 승인한다. 날짜변경선 횡단·극지·미등록 범위 및 이 광역 정책의 군대 이동 경로는 명시적으로 차단된다. 모든 세계사 주제가 무조건 지원된다는 판정은 아니다.
