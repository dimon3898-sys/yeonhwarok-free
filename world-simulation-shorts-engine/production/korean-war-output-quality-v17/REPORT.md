# 한국전쟁 첫 구간 실제 출력 품질 감사

2026-11-08 KST. 새로 첨부된 69761.mp4와 WORLD_ENGINE_STUDIO_VIDEO.mp4는
동일한 SHA256을 가진 파일이며 첨부 SHA256SUMS와 일치한다. 1080×1920,
30fps,10초,컨테이너상300프레임,무음이고 전체 디코드 오류는 없다.
이는 이번 첨부 파일의 기술 검증이다. QUALITY_SUMMARY 및 실제 작업·이미지
증명은 첨부되지 않았으므로 정확한 작업ID나 GPU 실행 환경까지 확정하지 않는다.
기존 PASS는 재실행하지 않았다.

**시각 품질 판정은 FAIL_REFERENCE_TARGET_NOT_MET다.** 레퍼런스64306.mp4와
비교하면 정보 밀도,강조 크기,지형·해안 세부,색 구분,사건 전개가 부족하다.
라벨 엔진 전체 미연결을 원인으로 단정할 증거는 없다. 영상에 한국전쟁,
낙동강 방어,인천상륙작전,날짜,노란 핀과 파란 글자 발광이 실제로 보인다.

REFERENCE_V1은 현재 라벨 스타일·핀·문자 등장 기능의 이름이다. 그 값을
지정했다고 레퍼런스 영상 전체의 미술·데이터·연출이 자동 적용되지는 않는다.
폰트 선호 크기는COUNTRY48,EVENT56,NUMERIC52px이며,현재 label 입력
스키마에 임의 fontSize나 자유 화면 배치 필드는 없다.

## 연결 여부와 판정 범위

보존된 정식 입력과 ANALYSIS_1의 canonical SHA는
ffc9cf86546776b36f3909d278114a7a064f0f15832412964a474f48691a257f로 같다.
컴파일 결과에서도 REFERENCE_V1/CONTEXT/NONE이 유지된다. 배포 manifest에
고정된 label layer·label validator·director events의 해시와 조사한 코드가
일치한다. 보존된 FRAME_192/210 진단은 라벨이 겹침이나 폰트 오류로 빠진 것이
아니라 OUTSIDE_EVENT_TIMING으로 제외됐다고 기록한다. 이 진단은 기존 CPU
증거이며 이번 GPU 작업 원본이라고 주장하지 않는다.

첨부 영상의 형식·전송은 정상이다. 인코딩 압축이 시각 품질에 전혀 영향을
주지 않는다고 단정할 수는 없지만, 확인된 공백·소형 핀·균일 영역·원본 해상도
문제는 입력과 렌더링 구성 단계에 존재하므로 비트레이트나 GPU 교체로 해결되지 않는다.
v13–v16의 JSON 읽기·시작 pin·PID 수정은 실행 안정성 수정으로, 이 연출을
개선한 변경이 아니다. 기존 기술 PASS는 시각 품질 PASS로 승격하지 않는다.

## 다음 최소 작업

1. 기존 데이터와 원본 입력은 보존하고 별도 후보 입력에서 HERO 핀,라벨 시작·유지
   시간,사건·지명 배치,영역 강조 강도와 카메라 체류 시간을 조정한다.
2. 바뀐 입력에 한해 정식 컴파일·사전검사와 라벨 가시성/화면 배치를 무료 검수한다.
   기존 PASS 전체나 동일 입력 GPU 렌더는 반복하지 않는다. 임의 fontSize 필드를
   넣거나 별도 영상 편집기로 대체하지 않는다.
3. 근접 지형 디테일은 현재 자료의 한계를 명시한다. 더 상세하고 출처가 검증된
   자료가 정식 입력 경로에 연결되기 전에는 레퍼런스 수준이라고 보고하지 않는다.
4. 역사 전선·상륙 경로는 근거 자료가 없는 상태에서 만들어 넣지 않는다.
   첫 구간 시각 FAIL을 해결하기 전에 둘째 구간을 같은 설정으로 유료 실행하지 않는다.
