# 범용 자동 연출 감독 V3

기존 정식 presentation compiler에 HISTORICAL_STATES_V3 선택을 추가했다. V1/V2 구현과 Area V3, Mercator 투영, 지형 파일 및 좌표는 보존한다.

6초는 인접 상태 2개(변화 1회), 20초는 4개(변화 3회)를 시간순으로 선택한다. 일부 시기 표기와 omittedStates를 제공한다. 전체 역사 기간을 모두 재현한 영상이라고 주장하지 않는다. 기준 영상에서 관찰한 108프레임 카메라, 25프레임 영역 등장, 47프레임 읽기 구간을 순차 배치한다. 완전 정지와 순차화는 설계 선택이다. 실제 원본 카메라 행렬은 없고 2D 화면 운동만 추정했다.

카메라는 V2의 실제 소스 적합성 검사를 재사용하고, 변화 지역과 최종 범위를 추적한다. 확대는 실제 지도 해상도 한도 안에서만 수행한다. 각 전환 직전 카메라 이동을 완료하고, 전환 및 읽기 구간 동안 고정한다. 추가/삭제 영역은 기존 차집합과 Area 패스 그대로이며 효과 강도는 화면 점유율에 따라 결정한다. 군사 경로나 전투 위치는 생성하지 않는다.

20초의 한 상태 슬롯에는 전환 이후 읽기 및 다음 카메라 이동도 포함된다. V3 presentation adapter는 기존 Area STATE_TRANSITION 공개 연산의 duration_frames만 실제 25프레임으로 바꾼다. 원자료 좌표와 세계 시간은 유지한다. 라벨 연도는 실제 영역 전환의 중간점에 맞춘다. 기존 라벨 계층의300프레임 제한 두 곳을 공개600프레임 계약에 맞췄다. <=300프레임 동작은 동일하다.

검증 범위는 신규 V3와 추가 연결만이다. 이전 PASS 테스트/영상은 재실행하지 않았다. 20초는 컴파일 및600개 모델 프레임 검증이고 실제20초 MP4 제작 주장은 하지 않는다. 최종 시각 품질은 새 CPU 영상과 레퍼런스 직접 비교 후 별도 판정한다. 지형 소스 한계, 북쪽 구도 제한과 원본의 근접지형 디테일 격차는 남을 수 있다.
