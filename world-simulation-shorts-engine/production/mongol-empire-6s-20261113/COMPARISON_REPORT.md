# 기존 영상 비교 기준 확보

70345.mp4와 70369.mp4 원본을 확보했다. 70369.mp4의 SHA256은 일본 V3 최종 CHECKPOINT의 영상 SHA256과 일치한다. 기존 영상 렌더나 기술 PASS 검사를 재실행하지 않았다. 사용자 요청에 따른 **새 비교 지표와 대표 프레임 추출**만 수행했다.

측정: ffmpeg로 각 원본의 180프레임을 160×284 회색조로 분석한 뒤 인접 프레임 절대 차이의 평균을 계산했다. 차이가 8/255를 넘는 픽셀의 전체 평균 비율은 각각 17.924%, 3.891%다. 밝기·텍스처·색상·카메라·이벤트가 모두 섞인 값이므로 카메라 이동량이나 화질 점수로 쓰지 않는다. 기존 샘플의 평균 변화량이 약 3.18배 크지만 ‘3.18배 더 좋은 영상’을 뜻하지 않는다.

`evidence/EXISTING_SAMPLE_COMPARISON.jpg`는 원본 두 편에서 0/1/2/3/4/5.966초를 추출한 비교판이다. 몽골 영상의 대표 프레임이 아니다. 영상 내용에 대한 평가는 이 추출 화면과 전체 프레임 밝기 분석을 근거로 하며 실시간 재생 검수로 표현하지 않는다.

몽골 MP4가 없으므로 요구한 180프레임 지도·영토·카메라·라벨·파동·깜빡임·최종 안정성 검사는 모두 **NOT_RUN_BLOCKED**다. 기존 일본 영상의 PASS를 몽골 영상으로 전용하지 않는다.
