# 한국전쟁 20초 통합 샘플

두 입력은 기존 WORLD_ENGINE_PRESENTATION_PROMPT_V2 10초 경로를 사용한다. 각 300프레임, 1080×1920, 30fps이며 기존 compose_segments로 600프레임을 연결한다. 새 장시간 렌더러는 없다.

| 구간 | 주요 정보 | 실제 구현 |
|---|---|---|
| 0–5초 | 1950년 9월 초 낙동강 방어 | 한반도에서 대구 지역으로 이동, 사건·날짜 라벨. 대구 핀은 방어선 측량점이 아니다. |
| 5–10초 | 9월 15일 인천상륙작전 | 인천 도시 좌표로 이동, 이름표·날짜·위치 강조 |
| 10–15초 | 서울 방향 진격 | 인천–서울 사이 방향 도식의 점진적 등장, ‘진격 방향(개략)’ 표시 |
| 15–20초 | 9월 28일 서울 수복 | 서울 중심 고정 구도, 사건명과 날짜 유지 |

## 입력과 사용 조건

- `KOREAN_WAR_20S_PART_01.json`
- `KOREAN_WAR_20S_PART_02.json`

현재 배포된 variant-pin-fix 이미지에는 최신 reference 스타일과 이번 연결 보완이 없다. 두 입력을 기존 배포 이미지에 바로 넣으면 안 된다. `SOURCE_SEAL.json`과 `DEPLOYMENT_PLAN.json`이 지정하는 새 후보 이미지가 필요하다.

## 역사·좌표 범위

국가보훈부와 국가기록원의 사건 설명·날짜를 대조했고, 기존 80초 자료의 인천·서울 연표를 재사용했다. 도시 좌표는 저장소에 보존된 Natural Earth 원본 feature와 대조했다. 지형은 기존 한국 지역 원본 래스터다. 현대 한국 내부 경계를 1950년 전선으로 오해하지 않도록 표시를 끈다.

검증된 1950년 9월 점령면·전선 좌표와 정확한 해상 접근 경로는 확보하지 못했다. 이 샘플은 해당 요소를 만들지 않는다. 노란 면은 현대 지리적 배경 강조이며, 서울 방향 선은 실제 부대 이동 경로가 아니다. 원본 웹페이지 바이트를 보존했다고 주장하지 않으며, source SHA는 별도로 작성한 출처 검토 기록을 식별한다.

## 기존 PASS 보존

기존 10초 성공 영상·라벨 355개·카메라·Area V3·범용 합성기를 다시 만들지 않는다. Nov5 영구 기록 실패/정체 모의검증과 이전 reference 300프레임 PASS는 재실행하지 않았다. 삭제된 gCube 컨테이너의 private 파일 및 stdout/stderr 회수는 시도하지 않았다.

새 A1은 자료 등록과 보조 국가 연결에서, A2는 이미지에 없는 한국 지형 파일에서, A3는 독립 구간 첫 장면의 이전 상태 요구에서 멈췄다. 모두 캡처 전 실패다. 각각의 기록을 유지하고 해당 연결만 보완했다. A4가 새 두 구간의 실제 출력과 합성을 검증한다.

## 검수와 실행

실제 프레임과 MP4를 본 뒤 `REFERENCE_COMPARISON.json` 및 CHECKPOINT를 갱신한다. CPU 검사는 gCube/NVIDIA 실행 또는 레퍼런스 동등 품질을 증명하지 않는다. 현재 실제 gCube 마운트에서 외부 저장소로 첫 기록이 회수되는지는 미확정이다. 다음 별도 승인 실행에서는 캡처 전에 그 기록을 외부에서 읽어야 한다.

유료 GPU는 두 입력, 이미지 digest, 비용·시간·재시도 상한을 특정한 별도 승인 전에는 실행하지 않는다. 성공 구간이 있으면 그 파일을 보존하고 실패 구간만 후속 승인 대상으로 삼는다.
