# 64306 레퍼런스 장면 역설계

값 구분: 프레임·PTS=기존 측정값, 카메라 변환=기존 추정값, 시각 역할=관찰 주석, 새 영상 연출=설계 목표. 모든 구간은 0 기반 [시작,끝)이다. 영상 SHA256은 기존 증거와 첨부 파일이 일치한다. 기존 디코딩·추적 검사는 SKIP했다.

| 구간 | 시간 | 목적·화면 구성 | 경로·지도·효과·정보 | 다음 장면 연결·재현 방법 |
|---|---:|---|---|---|
| R0 0–29 | 0–0.967초 | 안도라 소영역 설명의 끝부분. 작은 붉은 영역, 주변 주황·파랑, 흰 지명 카드·면적 표기 | 미세 움직임 후 끝에서 축소/전환. 색 아래 지형 질감, 밝은 경계 | 완결된 도입으로 오해하지 않는다. 새 주제에서는 맥락 제시로 대체. 기존 영역·라벨·카메라 설정 후보 |
| R1 29–30 | 0.967–1초 | 흐림을 동반한 화면 교체 | 카메라 복원 불가 | 이 1프레임 전환을 역사적 사건으로 사용하지 않는다. 새 영상에서는 생략 가능 |
| R2 30–175 | 1–5.833초 | 노란 스페인을 유지하며 유럽·북아프리카 관계를 보여줌 | 지형 특징점 축척 약 0.210배(추정). 스페인 축소, 유럽 흰색/아프리카 노란 경계가 넓게 보임. 해양 어두움 | 광역 상황 설명 후 선택 지역으로 접근. 기존 geographic camera의 zoom-out과 지역 fill 사용 후보. 역사적 주변 국경은 자료 없이 복사 금지 |
| R3 175–283 | 5.833–9.433초 | 광역에서 해협으로 접근, 모로코 위치를 강조 | 축척 약 13.073배(추정), 청록 영역 205–229 등장. 핀이 화면 중심 근처에서 대상을 잡아줌 | 카메라와 강조 동시 진행. 청록 등장 약 0.833초는 표시 효과이며 정복 과정 아님. 역사 변화와 별도 채널로 설계 |
| R4 283–330 | 9.433–11초 | 세우타·멜리야를 읽는 시간 | 약 1.567초, 완전 정지 아님. 축척 1.020배, 작은 재구도. 세우타 289부터, 멜리야 311부터 파란 강조 | 읽기 이후 세부 대상으로 이동. 기존 label layer 배치·등장 시간 대응 후보. 파란 강조와 핀 모양의 정확한 동일성은 코드 감사 필요 |
| R5 330–452 | 11–15.067초 | 중앙 노란 핀을 따라 북아프리카 해안의 작은 장소까지 접근 | 핀 334–340 등장, 363 전후 기존 두 지명이 화면 밖으로 이탈. 바다·해안 질감에서 건물 수준 디테일까지 변화. 추정 축척 48.885는 바다 구간 추적 결손으로 불완전 | 약 4.067초 접근의 속도·완급을 재사용하되 축척 숫자 그대로 복제 금지. 해안 세부 지도 소스는 UNKNOWN; BMNG만으로 건물 디테일 재현 불가 |
| R6 452–575 | 15.067–19.167초 | 근접 지형의 경계·길이를 설명 | 약 4.1초 동안 완만한 회전과 재구도. 459부터 574까지 노란 국지 경계선 발광 지속. 495에는 ‘85’, 500에는 ‘85 m’, 574에도 유지. 새 보완 주석: 숫자 등장 약 490±6, 완성 500 이내. 값의 역사·측량 진위는 검증하지 않음 | 지형·작은 건물·수면 texture가 색 아래 유지. 실제 역사적 전선 이동 없음. 새 주제는 출처 있는 변화 지역 및 연도 정보로 대응; 85m 복제 불필요 |
| R7 575–635 | 19.167–21.167초 | 검은 화면의 CapCut 아웃트로 | 지도 없음. 기존 추적값을 카메라로 해석하지 않음 | 새 영상에는 넣지 않음. 로고가 있다고 지도 제작 프로그램까지 CapCut이라고 단정할 수 없음 |

카메라 구간 경계는 기존 시각 주석 ±3프레임, 발광 ±4프레임이다. 화면 변화로부터 원본 카메라의 경도·위도·고도·렌즈·3D 행렬을 알 수 없다. 축척은 화면상 특징점 비율이며 실제 거리 비율이 아니다.

영상 내 그래픽: 영역 채색, 경계선, 노란 핀, 지명, 설명용 숫자·강조. 재현 제외: 휴대폰 상태 표시줄, 좋아요·댓글·공유, 계정·설명·댓글, 하단 탐색 UI, 편집기 아웃트로. 원본 화면 비율 822:1920은 앱 화면이며 지도 영상 원본 비율과 같다고 보장할 수 없다.

재현 전략은 ‘대상 제시 → 넓은 맥락 → 선택적 접근 → 읽기 → 더 가까운 접근 → 결과 읽기’다. 이번 단계의 기능 연결은 후보이며 실제 경로·함수 검토 결과를 다음 단계 대응표로 확정한다.
