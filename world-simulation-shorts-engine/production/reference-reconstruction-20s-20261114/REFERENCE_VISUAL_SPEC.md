## 지도·색·경계

- 광역: 자연색 육지·산맥 음영, 깊은 청남색 바다. 밝은 노란 영역과 청록 영역이 시선을 구분한다. 정밀 색상 원값은 압축·화면 녹화 때문에 UNKNOWN.
- 근접: 건물·밝고 어두운 지표·수면 물결 질감이 보인다. 확대에 따라 다른 해상도 층이 쓰였을 가능성은 추론이며 소스·LOD 구현은 UNKNOWN. 색 overlay 아래의 명암이 남는다.
- 투명도: 배경 원본 픽셀을 알 수 없어 alpha 수치 역산 불가. ‘채색 후에도 질감이 읽히는 상태’를 결과 목표로 삼는다.
- 작은 장소 외곽은 가늘고 밝은 선, 육지 연결부는 더 굵은 노란 core와 넓은 halo. 500프레임 보완 crop에서 시각적으로 core 약 5–10px, 국지 glow의 밝은 띠 약 10–20px, 퍼진 halo 수십 px 수준으로 추정한다. 임계값에 따른 객관적 선폭 측정은 없으므로 정확 수치로 사용 금지. 목표 화면 1080px로 단순 비례 복사하지 않는다.
- 레퍼런스에서 정복에 따른 경계 이동은 관찰되지 않는다. 화면상 외곽 이동 대부분은 카메라 변화다. 205–229 청록 fill 등장은 지역 표시이며, 459–574 glow는 국지 경계 강조다.
- 압축 artifact, 작은 thumbnail 손실, SNS 글자·UI를 지형 디테일로 계산하지 않는다. 현재 BMNG 1분 소스로 건물 단위 디테일을 주장하지 않는다.

## 구도·라벨

시선이 가는 대상은 지도 중심권에 머무르고 주변 지형으로 위치 관계를 이해한다. 세우타·멜리야 라벨은 순차적으로 강조된다. 노란 핀은 접근 중 목표를 유지해 주고, 가까워진 뒤에는 거리 숫자로 정보가 바뀐다. 화면 가장자리 여백의 정확 수치와 지리 대상 전체 점유율은 검증된 object segmentation이 없으므로 UNKNOWN이다.

새 CSV의 apparent_color_occupancy는 기존 103×240 thumbnail의 안전 ROI에서 노랑·청록 HSV 마스크 비율을 계산한 보조 proxy다. 가려진 영역·라벨·해안 전체를 복원하지 않으며 역사 영토 면적이나 완전한 대상 점유율이 아니다. 원본 색공간/압축 영향이 있어 지리 좌표 fitting에 직접 쓰지 않는다.
