# 600프레임 시간 감독

0 기반 [시작,끝), 30fps. 원본 분석은 재실행하지 않았다. R7 575:635는 편집기 아웃트로라 제외한다.

|단계|기존 원본|새 설계|차이|
|---|---:|---:|---|
|도입|29f + 1f 화면 교체|30f / 1초|화면 교체를 도입에 흡수|
|광역 이동|145f|145f / 4.833초|시간 유지, 지리·이동량은 몽골 source에 맞춤|
|접근|108f|108f / 3.6초|시간 유지|
|읽기|47f|47f / 1.567초|미세 움직임 대신 정지|

|최종 결과|123f|148f / 4.933초|20초 맞춤 +25f, 정확한 hold로 설계|

카메라 주요 이동 합계 375f/12.5초로 기존 구간 분류를 유지한다. 영토 변화 177:283의 106f/3.533초는 새 역사 상태 연결을 위한 **설계값**이다. 원본 205:230의 25f 청록 표시를 정복 속도로 해석하지 않는다. 106개 기존 도형은 원래 배열 그대로 한 번씩 재생하며 역사 관측 시점이나 진군 순서를 뜻하지 않는다.

최종 상태는 283부터 읽을 수 있다. 283:330은 47f 읽기, 330:452는 122f 제한 접근, 452:600은 148f 결과 유지다. 발광은 변화 구간에서만 실제 boundary band를 따른다. 283:301의 18f에는 기존 added/removed 색 안정화만 적용한다. 출처 없는 정적 85m 발광선은 만들지 않는다.

상대 확대: 새 광역 0.6907709669884669, 새 접근 1.513460460002223, 새 추가 접근 1.0847666363549404. 원본 추정은 각각 0.2103,13.0734,48.8851이며 마지막 값은 추적 결손으로 부정확하다. 이동 시간은 보존하지만 확대 강도는 source gate 때문에 훨씬 작다. 원본 실제 camera 좌표·3D 속도는 UNKNOWN이며 화면 픽셀 속도를 세계좌표 속도와 동일시하지 않는다.

C2 smootherstep을 투영 중심과 log scale에 적용하여 각 전환점의 속도·가속도를 0으로 연결한다. 카메라를 자동 프로필로 다시 생성하지 않고 명시 runtime 입력으로 전달하는 A안을 사용한다. GPU 전달과 glyph 실측은 후속 신규 계약 검사 대상이다.
