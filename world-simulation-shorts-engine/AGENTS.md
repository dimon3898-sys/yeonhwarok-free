# WORLD ENGINE 작업 통제

이 디렉터리의 모든 작업은 `docs/WORLD_ENGINE_UNIVERSAL_MASTER.md`를 먼저 적용한다.

- 작업 시작 전 원격 최신 HEAD, 작업 브랜치, CHECKPOINT와 증거를 확인한다. 완료된 유효 PASS는 SKIP한다.
- 현재 범용 엔진·입력 스키마·운영 이미지의 기능 대응을 먼저 조사한다. 코드 완료, 이미지 포함, 입력 호환, GPU 성공, MP4 검증, 운영 준비를 구분한다.
- 주제·역사 데이터·영토·카메라·지원 범위 내 길이 변경은 외부 데이터로 처리한다. 영상별 생성기·이미지를 만들지 않는다.
- 확인된 공통 기능 결함만 최소 수정한다. 이미지 빌드는 외부 입력으로 해결 불가능한 공통 코드/보안/계약 변경과 무료 검증의 증거가 있을 때만 한다.
- 기존 실제 GPU 성공 환경과 복구 이미지를 보존한다. 과거 성공을 현재 노드 성공으로 간주하지 않는다.
- 기존 PASS 재검증 전 무효화 증거, 영향 범위, 최소 검사를 기록한다. 전체 PASS 재실행 금지.
- 해결되지 않은 FAIL/BLOCKED에 의존하는 단계는 진행하지 않는다. 독립적인 무료 조사·설계·공통 기능 개발은 계속한다.
- GPU/gCube/Studio 유료 실행은 매번 목적·digest·사양·시간·비용·재시도·종료 조건에 대한 별도 승인이 필요하다. 현재 GPU 실행 승인 없음.
- main 수정, reset, force push, 증거 삭제, 검증 우회, HISTORICAL의 GENERAL 위장 금지.
- 작업 결과와 CHECKPOINT를 기존 작업 브랜치에 저장하고 원격 내용을 확인한다. 보고는 신규 성과·차단·다음 행동만 작성한다.
