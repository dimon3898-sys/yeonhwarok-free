# 기획 의미 검증

과거 연도나 날짜의 지도·국경·영토·해안 상태를 요청하면 현대 GIS로 대체하지 않습니다. UTC 실행 날짜보다 이전인 지도 상태는 `UNSUPPORTED_VISUAL_REQUIREMENT`와 `HISTORICAL_GIS`, `TIME_MORPH` 요구를 반환합니다. 최근 과거 연도도 같은 규칙을 적용합니다. ISO·슬래시·점으로 구분한 날짜, 한국어 연월일, 영문 월 이름 날짜를 확인하며 현재 연도 안의 지난 날짜도 구분합니다. 역사·고대·중세·기원전 지형 요청도 기존 차단 규칙을 유지합니다. 실제 역사 자료나 시간 변형 알고리즘을 구현한 것은 아닙니다.

연도만 포함된 민간 항공 주제는 현재의 검증된 지리 위에 여정을 시각화할 수 있습니다. 항공편 번호와 영상 길이 숫자는 지도 연도로 해석하지 않습니다. 현재 날짜의 국가 위치 비교는 기존 비교 모듈을 사용합니다. 과거 지형을 요청한 주제를 현재 지도에 조용히 대입하는 것은 금지합니다.

해상 나레이션은 실제 Scene 시계·운하 차단 사건·항로 시작/진행 단계로 선택합니다. 75초 예시는 로테르담 출발, 수에즈 접근, 기존 연결, 7일 폐쇄 가정, 희망봉 우회 선택, 경로 길이 차이, 같은 연결점의 다른 항로, 싱가포르 접근, 비교 범위 설명 순서로 진행합니다. 이전의 공개 GIS 그래프 구현 설명을 대사에서 제거했습니다.

거리 차이는 렌더에 사용하는 출처 있는 해상 경유점의 구면 길이에서 계산합니다. 영상의 압축된 이동 시간은 실제 선박 속도·운항 시간·배송 지연을 예측하지 않습니다. 폐쇄는 `ASSUMPTION`으로, 우회 결과는 그 가정에 연결된 `SIMULATION`으로 유지합니다. 수에즈에서 멈추는 참조 선박의 도달을 싱가포르 도착으로 설명하지 않습니다.

20·40·60·75·180·183.5초 기획에서 보수적인 발화 길이 추정과 연속 대사 반복을 검사합니다. 이 검사는 실제 음성 합성 길이·직접 청취·시청 지속률 측정의 대체물이 아닙니다. 이미 저장된 프로젝트 계획은 수정하지 않으며 개선한 대사는 새 계획에만 적용합니다.

계획상의 의미 사건은 화면에서 실제로 그려질 수 있어야 합니다. 구조·출처 검사가 통과하면 보존된 Three.js 렌더러의 실제 카메라·지구 가림·항로·이동체·정보 레이어를 매30fps 시점에서 실행하는 사전 검사를 수행합니다. 설치된 폰트의 글리프 폭을 사용하며 카메라 이동이나 선언된 효과만으로 사건을 인정하지 않습니다. 검사 도구가 없거나 사건을 확인할 수 없으면 승인과 렌더를 차단합니다. 같은 입력·렌더러·도구·폰트의 결과만 캐시합니다.

시야 밖의 비필수 도시·국가 공개는 실제 움직이는 출처 있는 경로의 남은 구면 거리로 바꿀 수 있습니다. 기존 사건 ID·시간·인과관계와 카메라·항로·이동체를 유지하고 새로운 수치에 `M01`의 시각화 가정을 연결합니다. 페어 효과음은 같은 시각을 유지합니다. 정보 없이 제목만 바꾸거나 보이지 않는 물리 출발·도착을 수치로 대체하지 않습니다. 실제 운하 차단과 도착은 카메라의 제한된 상승으로 실좌표를 보여주고, 공유 경계 상태를 정확히 연결하며 다시 검사합니다.

네트워크 사건은 항로가 현재 카메라에서 처음 보이는 시각과 연결합니다. 독립 Scene 끝에 너무 가까운 정보와 앞 자막의 유지 시간에 가린 결말은 출처와 인과관계를 유지한 짧은 시간 보정 및 동기화된 효과음으로 읽을 구간을 확보합니다. 기존 onset·최소 노출·Retention 검사를 완화하지 않습니다. 국가 비교 카메라는 움직이는 가상 연결선 대신 검증된 국가 초점 좌표를 사용합니다.

실제600프레임 A20v001 감사에서 누락된 뉴욕 사건 E006을 사전 검사도 동일하게 찾았습니다. 나머지13개 사건의 최초 표시 시각은 기존 실제 감사와 모두 일치했습니다. 이는 해당 실패 회귀의 근거이며, 모든 미래 영상의 픽셀 품질을 보장하는 것은 아닙니다. 사전 검사는 WebGL·실제 래스터화·셰이더 밝기·텍스처 가독성·영상미를 검사하지 않습니다. 렌더 후 실제 post-draw 감사와 전체 영상 QC를 독립적으로 계속 수행합니다.
