## 사건 진행과 엄격한 freshness 확인

자동 Retention Gate는 계획 사건12개, native draw receipt12개를 검사하고 통과했습니다. native receipt 기준 첫3초4개, 평균1.2182초, 최대3.0초, 종류11개, 같은 종류 최대연속1개이며 카메라 움직임은 사건 수에 포함하지 않습니다. 이 숫자는 시청자 시청 지속률 실측이 아닙니다.

E005는 현재 production 계획에서 milestone_reveal입니다. 진행 중인 경로를 새 사건으로 중복 계산한 것이 아니라 새648km 정보가 실제로 등장합니다. E006은 Japan tint가 장면 초반부터 존재하므로, 새 JAPAN 라벨 공개와 기존 국가 fill을 구분해야 합니다.

**v001의 엄격한 사건 최초 등장 검사에는 수정해야 할 문제가 있습니다.** E011의 network receipt는10.7초에 처음 보고되지만 Tokyo→Taipei 경로와 세 번째 항공기는 실제로10.0667초부터 나타납니다. 10.7초에는 새 텍스트/별도 효과 없이 기존 활성 연결이 event window에 들어온 것입니다. E011의 최초 연결 등장과 E01213.7초 사이를 엄격히 잡으면3.6333초입니다. 따라서 자동 draw-eligibility PASS만으로 v001을 모든 사건 freshness 게이트 통과로 보고하지 않습니다.

부모 에이전트에게 이 원인을 전달했고, 새 S004 버전에서 해당 route/entity start_time1.05→1.7 두 필드만 변경해 새 연결을 E011과 맞추는 최소 수정을 제안했습니다. 기존 v001은 보존합니다. 나머지 장면과 V3 지구의 재렌더를 요구하지 않습니다. 수정 뒤 새 실제 프레임과 연결·cache를 검사해야 합니다.

## 시선·지리·레퍼런스 평가

원본 레퍼런스의 기존 전체 분석과 private contact sheet들을 직접 읽고 보았습니다. 밝은 육지/짙은 바다, 새 지역·이동체·변수의 순차 공개, 다음 사건 방향의 선행 카메라라는 원리를 비교했습니다. 문구/전쟁 구도/사진을 복제하지 않았으며 private 업로드 프레임을 배포하지 않습니다.

기존75초의 이미 존재하는26.25초 모바일 캡처는 밝은 사막·구름과 흰 자막/경로가 겹쳐 정보가 약해지는 사례였습니다. 새 FLAT의 선명한 육지/짙은 바다와 fog/cloud 없는 정보 화면은 이 문제를 분명히 개선했습니다. 서로 다른 지리/장면을 비교한 관찰이며 영상 전체를 측정한 사용자 평가가 아닙니다.

평면 구간의 해안선과 국가 GIS는 기존 Natural Earth1:50m 벡터입니다. NE1 원본21600×10800에서 East Asia2880×4380을 업스케일 없이 추출해 실제 지형색과 shaded relief를 살렸습니다. 이는 실제 DEM 지형 변위가 아닙니다. 2K topology의 재질 bump와 원본의 relief가 합쳐진 절제된 지도 깊이입니다.

AUTO FOCUS는 S003에서 Tokyo→Taipei→Tokyo로 바뀌고 S004에서는Taipei입니다. NEXT EVENT CAMERA는 새 변수 정보가 실제1.0초에 eligibility를 얻기 전 .3333초부터(약한 weight)/.4667초부터(weight>.01) 그 방향을 예고했습니다. 지도 VFX는 도착 pulse/보류 barrier/우회 head이며 지형 전체를 가리지 않습니다.

## 아직 남은 약점과 범위

- v001 E011의 예약 사건과 실제 신규 연결 최초 등장 시간이 어긋났습니다. 이를 새 Scene 버전에서 맞추고 다시 실제로 확인해야 합니다.
- 대기 전환에서는 잠깐 상황 정보를 읽을 수 없습니다. veil opacity≥.5는19프레임/.6333초, ≥.9는7프레임/.2333초입니다. 전체 효과의 낮은 opacity까지 포함하면1.2333초입니다. 지도 투영 morph로 설명하면 안 됩니다.
- FINAL은 야간 HERO의 규모/네트워크 보상용이고, 지형 설명/해안선 세부 가독성은 앞의 FLAT보다 낮습니다. 수평선/구름을 보여주는 목적과 지리 설명 목적을 계속 분리해야 합니다.
- 완료된 경로는 약하게 표시해 현재 이동이 우선되지만375px에서는 과거 연결의 존재감이 작습니다. 주 경로의 실시간 방향은 이동체/밝은 head가 보조합니다.
- 정보 글꼴 최소76px 내부/38px 출력/약13.2px 모바일입니다. 도시명은 약18px 모바일로 읽히지만 긴 한국어 대본/자막 ON 혼합은 별도 모바일 검수가 필요합니다.
- 대륙 경계를 읽기 쉬워졌다는 판단은 실제 정지 프레임 기반입니다. 전문 제작자·실제 시청자·물리 휴대폰 청취/시청 테스트는 이 기록에 포함하지 않습니다.
- 네트워크/민간 가정의 한15초 검증입니다. 모든 향후 플러그인·전 세계 지형 atlas·양방향 Earth→Flat의 시각 품질을 이 영상 하나로 인증하지 않습니다.

## 실제 시간과 캐시

v001 실제 전체 pipeline은2864.333초(47분44.333초)입니다. FLAT12초 native 합1193.521초, 실제 초당99.460초입니다. 보존 V3 Earth3초 native1640.626초, 실제 초당546.875초입니다. 이 실제 영상의 관찰 비는약5.499배지만, 장면 내용과7탭/1탭 계산량이 달라 동일한 장면의 통제된 벤치마크가 아닙니다. v001은5개 모두 신규 렌더였습니다. 후속부분 수정 버전의 캐시 적중/시간은 별도로 기록해야 합니다.
