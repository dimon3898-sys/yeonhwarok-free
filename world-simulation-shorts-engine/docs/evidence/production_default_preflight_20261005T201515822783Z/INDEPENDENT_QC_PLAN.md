## Gates before the only 10–15-second render

- New requests select PRODUCTION_DEFAULT, but stored old Scene JSON remains valid without new fields. Old renderer hashes and cache keys must remain stable for existing immutable inputs.
- The default new plan renders v004 Flat for information scenes and V3 Earth/HERO for actual important reveals; visual proportions are guides rather than rigid percentages. Changing only a metadata label is insufficient.
- PACE_FAST changes deterministic per-primitive timing curves, travel/route/focus/transition timing or Scene duration. Full-video `setpts`/global playbackRate is prohibited. Compare NORMAL and FAST at identical actual local timestamps and final endpoints; preserve narration pitch/playback speed and event synchronization.
- Scene temporal continuity, route progress, entity pose and active state remain valid at cuts. A shorter travel interval should settle at the intended target rather than jump back on entry to the next Scene.
- Dead Time Gate rejects camera-only stretches, excessive travel holds, transition veils and excessive post-Peak holds, while retaining minimum information/Peak reading exposure. Do not count camera, glow, particles, repeated active country fills or deleted captions as new semantic events.
- Direct map labels include names or concise sourced numbers connected to country/city/route geometry. Default hook/ending prose is suppressed; explicitly user-authorized title input is handled separately. No guessed coordinate or unsupported effect fallback.
- Country tint uses distinct limited colors plus border/label/focus, preserving the underlying relief. Primary route contrast/head/width is stronger than secondary routes and remains readable at 375 px.
- SFX has event-category/intensity/license metadata and deterministic seeded variant selection with recent-history anti-repeat. The report lists actual file hashes rather than assuming different variant names mean different audio.
- Existing controls TTS, subtitles, BGM and new SFX ON/OFF work independently. Speech priority ducks strong SFX and BGM smoothly; do not accelerate TTS. Audio cases must test actual nonzero narration and overlap, not just a sample with TTS OFF.
