## 레퍼런스 A/B에서 확인한 리듬과 적용 범위

두 레퍼런스의 실제 이미지를 분석했으며, 완성된 원작 전체가 아닌 이미 진행 중인 Shorts 발췌 화면이다. 기기·플랫폼 UI와 끝의 CapCut 카드 2초를 이야기·정지 구간·최종 보상에서 제외했다. 첫 프레임에 이미 존재하는 경로, 같은 효과의 지속적인 성장, 단순 카메라 이동, 자막 단어 교체를 새 사건으로 중복 계산하지 않았다.

| 비교 | 레퍼런스 A | 레퍼런스 B |
|---|---|---|
| 실제 이야기 화면 | 0–6.500초 | 0–12.133초 |
| 확인된 새 그래픽 사건 | 지리 세부 가독성 reveal 1회 + 방향 정보·상태 표식 2회 | 국가 공개 → 충격 → 새 지역 강조 → 이동체 등장 → 대응 → 새 이동 → 결과의 7개 onset |
| 사건 간격 | 후반 4.333/5.067/5.400초 reveal cluster 평균 0.533초. 전체 영상 빈도로 일반화하지 않음 | 6개 onset 간격 평균 1.694초, 최대 2.833초. 점진적 등장 시각은 약 ±0.1–0.2초 불확실성 |
| 완급 | 다음 작은 지역을 먼저 언급 → 약 2.7초부터 빠른 접근 → 읽기 위한 감속 → 새 관계 정보 | 빠른 이동 → 결과 읽기 → 다음 지역을 먼저 향하는 카메라 → 새 이동체·대응 → 다시 이동·결과 |
| 텍스트 | 지도에 연결된 지명과 설명 자막이 함께 존재 | 주로 아래 중앙의 짧은 나레이션 조각. 지리 좌표에 연결된 지도 라벨과 같지 않음 |

공통 원리는 **다음 대상 예고 → 가속 → 핵심 위치에서 감속 → 새로운 정보 → 짧은 결과 인지 → 다음 사건**이다. 사건 종류는 달라져야 하며, 한 효과를 계속 키우거나 카메라만 움직여 진행감을 대신하지 않는다. 카메라가 새 사건 전에 해당 방향으로 준비하고, 현재 사건을 읽을 시간을 남긴 뒤 다시 움직인다. 이때 보이는 짧은 settle은 완전 정지나 원작의 정확한 camera velocity=0을 측정한 결과가 아니다.

오디오는 디코딩한 혼합 PCM·파형·onset·loudness 기준으로만 분석했다. A/B에는 짧은 에너지 감소와 transient가 있지만 음성·음악·효과음이 섞여 있으므로 개별 효과음 개수, 정확한 SFX 파일, 모든 dip의 의도적 micro-pause, 청감상 동기화를 확정하지 않는다. 이 환경에서 첨부 오디오를 직접 듣는 기능을 사용할 수 없으므로 직접 청취했다고 보고하지 않는다. A의 약 2.371–2.551초 dip은 빠른 접근 전에 위치하나 이미지상 지리 이동은 계속되며, 두 영상의 export ending을 audio pause로 해석하지 않았다.

이번 **12초 / FAST_PLUS / TTS OFF / 자막 OFF / BGM·효과음 ON** 샘플에는 공통 원리만 번역한다. 기존 premium 지도 재질·실제 GIS·지형·AUTO FOCUS를 유지하고, 개별 카메라·경로의 가속과 감속을 조절하되 실제 이벤트·라벨·지리 좌표의 시간은 지킨다. 짧은 장소·거리·상태 정보만 해당 순간에 공개하며, 원본 나레이션 조각을 지도 라벨로 오인하거나 대본·국가 순서·색칠·무기/폭발 디자인을 복제하지 않는다. Peak에는 짧은 준비, 한 번의 주된 hit, 절제된 tail을 사용하고 생성한 원본 오디오 stem과 실제 시각 이벤트의 연결을 따로 검증한다.

이 분석은 구현 근거이며 새 샘플의 품질 통과 선언이 아니다. 최종 MP4의 실제 사건 onset·속도 변화·라벨 가독성·BGM/효과음 파형·모바일 재생·다운로드를 별도로 확인해야 한다. 레퍼런스의 짧은 발췌만으로 원작 전체 훅·최종 결론 또는 실제 시청 지속률을 입증하지 않는다. 참조 영상·추출 이미지·오디오는 검수용 비공개 자료로 유지하며 공개 산출물에 넣지 않는다.
