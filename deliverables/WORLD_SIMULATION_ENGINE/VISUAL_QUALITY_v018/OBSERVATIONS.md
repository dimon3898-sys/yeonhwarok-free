# 64458 실제 프레임 관찰

분석 대상은 사용자가 확인한 RTX4080S 완성본 `final (6).mp4`다. 레퍼런스 64306을 화질 수정 기준으로 사용하지 않았다. 24초, 30fps, 720프레임을 모두 디코딩했다. 최종 출력은 1080×1920이다.

| 시간 / 대표 프레임 | 직접 확인한 문제 | 소스와의 연결 | 판정 한계 |
|---|---|---|---|
| 0–3초 / F000 | WIDE 대륙 정보는 유지됨 | 작은 화면 footprint에서 기존 8K 소스가 충분히 활용됨 | 전체 지구에 같은 흐림이 발생한다고 볼 근거 없음 |
| 5–12초 / F240 | Suez 해안·사막 세부가 부드럽고, 밝은 육지가 국소 대비를 잃음. 왼쪽 바다에 넓은 반사 영역 | 확대 시 8K texel 하나가 약 7–8 최종 픽셀, 2K 높이 texel은 약 29–33픽셀. 기존 day 패턴과 실제 RGB 채널 상관 0.883–0.914 | 측정 사막 ROI의 RGB≥245 clipping은 0%. 하이라이트 hard clipping으로 단정하지 않음 |
| 14–16.5초 / F435 | CONTINENT_WIDE 지리 관계와 대륙 세부는 읽힘 | 같은 8K 소스지만 확대도가 낮음 | 구름·대기 전체를 줄일 이유가 확인되지 않음 |
| 19.5–24초 / F630 | Singapore 야간 도시광에 사각 덩어리, 거친 해안·육지 | 실제 gold 패턴과 기존 night 소스 상관 0.758. 밝은 도시광 연결요소 median 21×18픽셀 | 새 고해상도 night 자료 없음. gain 조절은 새로운 도시 세부를 생성하지 못함 |

Suez 사막 ROI(대표 F240)는 Rec.709 가중 8bit code 평균 234.59/255, p90−p10 6.72다. 91.9%가 luma≥230이며 모든 RGB 채널≥245 비율은 0%다. 이는 밝은 표면의 정보 대비 압축을 뜻한다. HDR 광도 실측값이 아니다.

`source-correlation.json`의 역투영 분석은 기존 저장 계획과 카메라 코드에 근거한다. 실제 GPU 진단 ZIP의 카메라 metadata를 복원한 것으로 취급하지 않는다. 원본 소스 투영 그림은 AFTER 렌더가 아니므로 비교 갤러리에 포함하지 않았다.

이번 카메라 QA에는 실제 Route/선박/항공기 표시가 없다. 이를 추가하거나 연출을 변경하지 않는다. AFTER NVIDIA 렌더는 NOT_RUN이다.
