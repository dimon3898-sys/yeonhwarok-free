서울–도쿄–타이베이의 중립적인 가상 민간 연결 시나리오입니다. 실제 좌표·지리와 구면 거리(FACT), 목적지·연결 보류 가정(ASSUMPTION), 해당 가정의 시각화(SIMULATION)를 구분합니다. 실제 항공 운항 결과·폐쇄·전쟁·기상 예측을 주장하지 않습니다.

이번 생성·수정 승인 기록은 사용자 지시에 따른 내부 15초 검증 QA이며, 사용자의 최종 스타일 승인 또는 75초 전체 렌더 승인이 아닙니다. 기존 MASTER V1/V2/V3와75초결과는 보존하고 기본 Planner의 Earth 설정을 유지했습니다.

새 지역에서도 엔진을 재사용할 수 있지만, 이번 native 지형 PNG의 검증 범위는 동아시아입니다. Natural Earth의 10m는 1:10 million 지도 축척 자료군이며 10미터 DEM이 아닙니다. 지형은 공개 cartographic shaded relief입니다.
