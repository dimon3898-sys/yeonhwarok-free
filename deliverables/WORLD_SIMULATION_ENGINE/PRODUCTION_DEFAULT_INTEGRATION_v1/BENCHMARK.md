## FAST/NORMAL 비교의 범위

승인된 NORMAL 15초 구조를 FAST 12초로 설계했다. Scene duration과 내부 camera/zoom/route/entity/focus/transition timing을 수정했으며 전체 파일의 재생속도를 올리지 않았다. TTS rate는1.0이다. Peak에는 최소 인지 시간을 남겼다.

**15→12초는 구조·타이밍 비교다.** 이번에 동일 입력의 NORMAL 전체를 새로 렌더하여 FAST와 CPU 시간을 대조하는 통제 benchmark는 하지 않았다. 이 결과를20%의 실제 렌더 성능 개선이라고 주장하지 않는다.
