# QUALITY REPORT — MASTER v2 / ONE DEPARTURE

작성: 2026-10-04 UTC. 이 문서는 실제 파일 검사·프레임 관찰과 미검수 항목을 구분한다. 시청 지속률은 시청자 실험으로 측정한 수치가 아니다.

## 결과

**MASTER v2 제작 완료: 20.000초 / 1080×1920 / 9:16 / 30fps / H.264 / 600프레임.** 유음·무음 MP4와 실제 최종 MP4에서 추출한 네 장의 PNG를 생성했다. 무음 파일에는 audio stream이 없고, 두 버전의 video packet hash가 동일하다.

모든 600프레임을 원본 해상도로 decode·hash했다. black/empty map/exact duplicate/near-frozen map/text clipping/WebGL error/항공기 안전영역 이탈/주요 라벨 겹침은 **0건**. 지도 ROI 인접 차이 min **0.768/255**, median **3.358/255**; 첫 0.5초 min **3.184/255**. UI·자막 영역은 motion ROI에서 제외했다. 5초/10초 접합점의 지도 차이는 2.770/255, 4.168/255이며 전체 contact sheet와 실제 재생에서 순간이동은 보이지 않는다.

카메라 위치 변화는 프레임당 0.001932~0.071047 지구 반지름, 방향 변화 최대 **1.470°/frame**. 실제 배치 사전검사 600시점과 encoded frame audit 450시점에서 항공기 외곽/라벨 clearance를 검증했다. 기존 검수 첫 150프레임은 추가된 외곽 항목이 없지만, 같은 시각 소스에 대한 600시점 사전검사와 실제 인코딩 프레임 관찰로 확인했다.

최종 MP4의 **실제 20초 전체 재생 완료**: 375×667 모바일 크기 Chromium viewport, 원본 video 1080×1920, total 600 / dropped 0 / corrupted 0 / callbacks 600 / 최대 media callback 간격 0.033334초 / audio 685,303 bytes decode / error 없음. 최종 파일을 큰 1080×1920 CSS viewport로 재생한 별도 실행은 ended=true와 corrupt 0이나 player dropped 3을 보고했다. 두 실행과 파일의 600 decoded frame 무결성을 구분해 기록한다. 물리적 휴대폰 시험이나 assistant의 직접 청취를 수행했다는 의미는 아니다.

최종 AAC 실측 **−18.54 LUFS / −2.41 dBTP / 7.50 LU LRA**, clipping 없음. BT.709 matrix/primaries/transfer 및 full-range VUI를 보완한 뒤 수정 전/후 600개 RGB 프레임의 누적 SHA-256이 완전히 같은 것을 확인했다. 최종 프리뷰 시간은 **2.10 / 9.40 / 14.90 / 19.70초**다.

MASTER v1, 기존 GIS·자산·소스·문서는 그대로 보존했다. 83개 원본 SHA-256을 다시 대조해 변경 0건을 확인했다. v2는 별도 엔트리 `index_v2.html`과 별도 파일명을 사용한다. 기술·화면 자체 검수는 충족하며, 아래 남은 한계에 청감·실기기·시청 지속 실험의 미실행 범위를 명시한다.

## MASTER v1의 문제와 유지한 장점

v1의 실제 순서는 **싱가포르 → 서울 → 도쿄**였다. 새 요청의 순서인 **서울 → 도쿄 → 싱가포르**를 v2에 적용했다. 실제 공항 좌표, 구면 투영, GIS 국경·해안, 입체 항공기, 미세 지형 입력, 어두운 다큐멘터리 색조, 4K 내부 렌더 구조는 유지했다.

v1은 카메라와 항공기가 계속 움직이지만 새로운 상황의 종류가 적고, 큰 오프닝 정보가 오래 유지된다. 두 항로의 카메라 리듬이 유사하며 도시 불빛과 주변 네트워크가 약하다. 움직임을 유지하는 것과 시청자가 새로운 사건을 체감하는 것은 다르다.

## 가장 크게 바꾼 다섯 가지

1. **첫 3초**: 이미 이동 중인 카메라로 시작한다. 0.4초 서울 pulse/도시 불빛, 1.15초 항로 생성, 약 1.8초 입체 항공기, 2.75초 동쪽 목적지 암시를 순서대로 공개한다. 검은 화면·정적인 로고 인트로는 없다.
2. **상황의 진행**: 도쿄 도착 후 항공기가 잠시 화면을 비우고 8.4초에 주변 세 항로가 활성화된다. 10.15초 남쪽 항로로 전환하고, 싱가포르 도착 후 전체 연결망으로 결말을 만든다.
3. **카메라와 깊이**: 빠른 접근 → 감속 → 추적 → 확장 → 남쪽 방향 전환 → 14~16초 낮은 궤도/곡률 → 최종 pull-out. 연속 Hermite 보간에 banking·yaw·roll·원근감과 지표/대기 레이어를 결합했다.
4. **항로·이동체·가독성**: 가는 core, 약한 외부 glow, 작은 light head, 짧은 감쇠 trail과 입체 항공기. 주인공 항로는 주변 네트워크보다 밝다. 도시·공항 라벨을 키우고, 항공기의 실제 투영 외곽과 겹치지 않도록 부드럽게 여유를 확보한다.
5. **사운드 구조**: 오프닝 hit, 출발 sweep/pass-by, 도쿄 도착, 네트워크 확대, 남쪽 전환, 곡률 구간과 마지막 impact를 별도 cue로 설계했다. 음악 에너지도 20초 동안 단계적으로 변한다. 외부 음원은 사용하지 않았다.

## 지도·자산·라이선스와 현실성

Natural Earth 1:50m 국가/해안 GeoJSON(public domain), 보존된 Blue Marble 지표 및 topology, night-light 텍스처를 사용한다. URL·SHA-256·동봉 라이선스는 `assets/SOURCES.json`과 기존 README에 있다. 국경·해안과 선택 국가 폴리곤은 구면 위의 벡터 geometry다. 생성형 AI로 지도를 만들지 않았다.

새 구름/haze는 오리지널 절차적 노이즈 오버레이(CC0-1.0)다. 실제 기상·현재 도시 전력량을 나타내지 않는다. 실제 공항은 ICN 126.4407°E / 37.4602°N, NRT 140.3929°E / 35.7719°N, SIN 103.9915°E / 1.3644°N이다. 항로는 구면 대권거리 기준이며 시간·경로 높이는 영상 연출용이다. 측량 DEM을 displacement mesh로 구성한 지형은 아니다.

항공기 geometry와 음악·효과음은 오리지널이다. 원래 GIS·폰트 라이선스는 유지했다. 레퍼런스의 군사 내용, 대본, 아이콘, 지도 디자인, 음악은 복제하지 않았다.

반지름 6,371.0088km 기준 거리: ICN–NRT **1,258.11km**, NRT–SIN **5,357.55km**, 합계 **6,615.66km**. 화면에서는 정수 km로 표시한다.

## 검수 중 수정

첫 5초는 150프레임 전체 검사와 실제 재생을 통과했다. 수정된 10초는 300프레임 전체 검사에서 black/empty/duplicate/frozen/text clipping/WebGL error/항공기 안전영역 이탈/주요 라벨 겹침이 모두 0건이었다. 첫 0.5초 map difference 최솟값 3.184/255, 10초 전체 최솟값 0.845/255, median 3.264/255. 무캡처 전체 재생에서는 300프레임, dropped/corrupt 0, 최대 frame callback 간격 0.033334초를 확인했다. 캡처를 병행한 이전 재생에서 player dropped 2가 기록돼 보존하고, 캡처 없이 재검증했다. 파일의 300 decoded frame에는 누락이나 중복이 없었다.

- 주변 항공 네트워크가 너무 희미해 실제로 상황 변화가 보이지 않는 문제를 수정했다. 주 항로보다 낮은 밝기를 유지하면서 선 굵기·opacity를 올렸다.
- 저각 샷에서 지나간 도시명이 주인공 항공기보다 눈에 띄는 문제를 수정했다. 지난 도시 라벨은 낮추고 마지막 overview에서 다시 밝힌다.
- 중간 네트워크 장면의 떠 있는 항공기를 제거했다. 도쿄 도착 후 자연스럽게 사라졌다가 두 번째 출발 때 다시 등장한다.
- 10초 실제 재생 캡처에서 도쿄 도시명과 항공기 외곽의 여유가 부족했다. 도시 라벨에 연속적인 clearance를 적용하고 실제 silhouette/font bounds 겹침 검사를 추가했다. 원래 검사한 첫 5초는 시각적으로 같은 소스를 유지하고, 영향을 받는 5~10초만 새 이름으로 다시 렌더한다. 수정 전 리뷰 영상도 보존한다.
- 최종 컨테이너 검사에서 색상 matrix는 BT.709였으나 primaries/transfer가 미지정인 것을 발견했다. 그림을 재압축하지 않고 H.264 VUI/컨테이너 태그를 명시하고, 전후 모든 RGB 픽셀 동일성을 검증했다. AAC peak의 0.13dB 목표 초과도 −0.6dB gain으로 보완했다. 수정 전 v2 파일은 review_r1 이름으로 보존한다.

## 남은 한계와 60초 확장 전 해결할 사항

- 전세계 4K 지표/2K 지형 텍스처는 낮게 접근하는 샷에서 세부 지표가 부드럽다. 벡터 경계는 선명하지만 건물·고해상도 위성 타일·측량 DEM 수준은 아니다. 60초 확장 전 지역별 고해상도 GIS와 license/caching 전략을 마련해야 한다.
- 주변 세 항로는 의도적으로 배경에 가까운 밝기다. 세 도시의 주인공 연결은 명확하지만 광범위한 실제 항공망의 인상은 제한적이다. 더 큰 네트워크 이야기를 만들 때는 초점 유지와 연결 규모의 표현을 다시 설계해야 한다.
- 사용자 기기의 직접 청감은 검수하지 못했다. 이 환경에서는 소리를 assistant에게 입력할 수 없어 loudness/true peak/stereo/cue/파형·재생 decode로 검증했다. 요청에서 허용한 파형·타임라인 기준 검사와 실제 청취를 구분한다.
- 375px 모바일 축소 검수는 수행하지만 물리적인 휴대폰·YouTube 앱의 인코딩 및 기기별 display/speaker를 시험한 것은 아니다.
- 예상 시청 지속 개선은 연출·프레임 비교에 따른 자체 판단이다. 실제 audience retention이나 모든 사람의 취향에 대한 보장은 아니다.
- 재사용 가능한 카메라·지리 경로·강조·network·scene 모듈을 유지했지만 샘플의 shot timing은 직접 연출한 값이다. 전세계 자동 shot planning, 60초, TTS, UI, 대본·업로드 자동화는 구현하지 않았다.
- 다른 대륙 확장 전에는 날짜변경선·극지·대척점 경로, 국가별 라벨 충돌과 카메라 구도를 별도 검증해야 한다. 이번 세 도시 샘플의 성공을 전세계 자동 연출의 검증으로 확대해 해석하지 않는다.
- `insert_cinematic_clip()` 연결 구조는 유지한다. 실제 I2V 모델이나 외부 클립 디코더를 이번 영상에 넣지 않았다.
